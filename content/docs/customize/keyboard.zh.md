读者不碰鼠标也能读完你的文档：OINK 的每个交互式页面都响应二十九个单键快捷键，十个用于导航，九个用于对页面执行操作，十个用于调整样式。在任意页面按 {{< kbd "'" >}} 即可看到全部二十九个，当前页面用不上的键会变暗显示。快捷键默认开启，读者输入文字时自动让行，也可以按站点或按页面[关闭](#disable)。

## 导航 {#navigation}

| 按键 | 作用 |
| --- | --- |
| {{< kbd "W" >}} {{< kbd "S" >}} | 侧栏移动：在侧栏树中移到上一项 / 下一项 |
| {{< kbd "A" >}} {{< kbd "D" >}} | 收起 / 展开章节 |
| {{< kbd "Enter" >}} {{< kbd "Space" >}} | 打开侧栏中焦点所在的页面 |
| {{< kbd "Q" >}} {{< kbd "E" >}} | 按侧栏顺序翻到上一页 / 下一页 |
| {{< kbd "K" >}} {{< kbd "J" >}} | 沿页面目录跳到上一个 / 下一个锚点 |
| {{< kbd "X" >}} | 切换到下一种语言 |
| {{< kbd "R" >}} | 切换到下一个一级栏目 |
| {{< kbd "V" >}} | 切换到下一个版本 |
| {{< kbd "H" >}} | 打开浏览历史 |
| {{< kbd "G" >}} | 回到首页 |

### 侧栏 {#sidebar}

侧栏键在所有带侧栏树的页面上有效，而且不必先进入侧栏：焦点还在正文时按 {{< kbd "S" >}}，会从当前页在侧栏里的那一项直接移到下一项。焦点行的底色比「当前页」那一行深一档，「我在哪一页」和「光标在哪里」因此一眼可分。侧栏收在手机抽屉里或在桌面端被折叠时，第一次按键先把它打开。

焦点进入侧栏后，{{< kbd "↑" >}} {{< kbd "↓" >}} {{< kbd "←" >}} {{< kbd "→" >}} 与字母键作用相同；焦点在正文时，方向键仍是浏览器原生滚动。从右向左书写的语言里，{{< kbd "←" >}} 和 {{< kbd "→" >}} 随阅读方向对调，{{< kbd "A" >}} 始终是收起，{{< kbd "D" >}} 始终是展开。

焦点在页面项上时，第一次按 {{< kbd "A" >}} 回到所属章节，再按一次才收起它。{{< kbd "D" >}} 展开已收起的章节；章节已经展开时，进入它的第一个可见子项。没有自身页面的章节通过展开按钮获得焦点，用 {{< kbd "Enter" >}} 或 {{< kbd "Space" >}} 切换展开状态。{{< kbd "Esc" >}} 退出侧栏，焦点回到原来的位置。

### 阅读 {#reading}

{{< kbd "K" >}} 和 {{< kbd "J" >}} 的目标与右栏目录完全相同，落点与点击目录一致。无论跳多远，每次都是 100 ms 的滑动，上一段没结束也可以继续按。已经读到某一节中间时，{{< kbd "K" >}} 先回到这一节的开头。页面没有标题时，这两个键改为滚动一小段。在首页，它们在落地页的各个分区之间跳转。

{{< kbd "Q" >}} 和 {{< kbd "E" >}} 按侧栏显示的顺序翻页，而不是按日期，并且跳过已收起的分支，因此翻页顺序与侧栏焦点顺序始终一致。栏目入口页本身也是一项：在博客栏目的边界，顺序是上一栏目的最后一篇、下一栏目的入口页、再到它的第一篇。页面没有侧栏树时，翻页改用页尾翻页器，再其次是 `<head>` 中的 `rel="prev"` 与 `rel="next"`。

### 语言、栏目与版本 {#switching}

这三个键在所有交互式页面上有效，没有其他选项时不做任何事：

- {{< kbd "X" >}} 切换到下一种语言，到最后一种后回到第一种。它打开当前页面的译文；页面没有译文时，打开该语言的首页。
- {{< kbd "R" >}} 在同源的顶部导航栏一级入口之间循环，跳过外部链接和导航栏上的工具按钮。
- {{< kbd "V" >}} 打开 `params.versions` 中下一个配置了 URL 的版本，到最后一个后回到第一个。

### 浏览历史 {#history}

{{< kbd "H" >}} 打开一个与搜索框外观一致的列表，按时间倒序列出你在本站读过的页面。当前页面不在列表里，所以按 {{< kbd "H" >}} 再按 {{< kbd "Enter" >}} 就能回到上一页。

| 按键 | 在历史列表中 |
| --- | --- |
| 直接输入 | 按标题和路径筛选，每个词都要匹配 |
| {{< kbd "↑" >}} {{< kbd "↓" >}} | 选择一项 |
| {{< kbd "Enter" >}} | 打开所选页面；{{< kbd "Ctrl" "Enter" >}}（macOS 上为 {{< kbd "⌘" "Enter" >}}）在新标签页打开 |
| {{< kbd "Shift" "Delete" >}} | 删除所选的一项 |
| {{< kbd "Esc" >}} | 关闭列表 |

**清除历史** 会删除所有已存访问记录，包括当前页。命令面板里也有一条 **浏览历史** 命令，打开的是同一个列表。

浏览历史在当前浏览器的 `localStorage` 中保存最近 100 个页面，键名带有站点的基础路径，例如 `td-history:/`。同一站点的各种语言共用一份历史，同一域名下的不同站点各自独立。OINK 不会把它发送到任何地方。只有开启键盘导航的页面才会记录历史，它没有单独的开关。

{{< kbd "G" >}} 打开当前语言的首页；已经在首页时，它滚回页面顶部。

## 操作 {#actions}

| 按键 | 作用 |
| --- | --- |
| {{< kbd "/" >}} {{< kbd "F" >}} | 搜索 |
| {{< kbd `\` >}} {{< kbd "C" >}} | 以纯命令状态打开命令面板 |
| {{< kbd "U" >}} | 编辑当前页面 |
| {{< kbd "N" >}} | 新建子页面 |
| {{< kbd "I" >}} | 新建文档议题 |
| {{< kbd "O" >}} | 展开或折叠页面中所有可折叠的内容 |
| {{< kbd "P" >}} | 打印页面 |
| {{< kbd "[" >}} | 在 ChatGPT 中打开 |
| {{< kbd "]" >}} | 在 Claude 中打开 |

### 搜索与命令 {#search}

{{< kbd "/" >}} 以搜索状态打开[命令面板](/zh/docs/customize/panel/)，{{< kbd `\` >}} 以纯命令状态打开它。这两个键属于命令面板本身，关闭键盘导航后仍然有效；{{< kbd "F" >}} 和 {{< kbd "C" >}} 是键盘导航提供的对应键。macOS 上的 {{< kbd "⌘" "K" >}} 和其他系统上的 {{< kbd "Ctrl" "K" >}} 在任何位置都能打开面板，包括文本框中，再按一次则关闭。在不便按出 {{< kbd `\` >}} 的键盘布局上，可以改按 {{< kbd "C" >}}，或在搜索框开头输入 `>`。

命令面板需要开启本地搜索（`params.offline_search: true`），否则这四个键不做任何事。

### 页面操作 {#page-actions}

{{< kbd "U" >}}、{{< kbd "N" >}} 和 {{< kbd "I" >}} 执行的是标题旁页面菜单里的同一批操作，并在新标签页打开目标。三者都需要站点配置了[代码仓库](/zh/docs/customize/repository/)；{{< kbd "U" >}} 和 {{< kbd "N" >}} 还要求页面有源文件，因此在标签列表等自动生成的页面上不做任何事。{{< kbd "P" >}} 打印当前页面，与浏览器自带的打印命令完全相同。

{{< kbd "[" >}} 和 {{< kbd "]" >}} 在新标签页中把当前页面交给 ChatGPT 或 Claude，前提是站点开启了 `params.ui.page_context_menu.assistant_links`。

### 展开或折叠全部 {#expand-all}

{{< kbd "O" >}} 一次展开页面上所有能折叠的内容：侧栏章节、右栏分组（目录、反向链接、术语云）、可折叠的提示框、文件树、「显示更多」列表，以及被截短的长代码块。如果它们已经全部展开，{{< kbd "O" >}} 就把它们全部折叠，只保留当前页面所在的侧栏分支，你不会因此迷失位置。页面上方的内容伸缩时，你正在读的那一行保持不动。

导航栏下拉菜单等弹出菜单不属于可折叠内容，保持关闭。已收起的侧栏或右栏也保持收起，需要用它们自己的按钮恢复。

### 禅意模式与双列视图 {#zen}

{{< kbd "Z" >}} 隐藏导航外壳，只留下正文：在首页隐藏顶部导航栏和页脚，在文档页还会隐藏左右两栏和浮动按钮。这个选择在当前浏览器标签页内保持，并在首帧之前恢复，所以用 {{< kbd "Q" >}} {{< kbd "E" >}} 连续翻页时不会闪烁。手机宽度下顶栏始终保留，因为它是回到导航的唯一入口。外壳隐藏期间，侧栏键不做任何事。

站点设置了 `params.ui.compare: true` 且当前页有译文时，{{< kbd "B" >}} 打开[双列视图](/zh/docs/customize/i18n/#bilingual-view)；在任一栏中再按一次即可关闭。

在发布了 Markdown 输出的站点上，{{< kbd "M" >}} 在新标签页打开当前页面的 Markdown 源码。

### 外观 {#appearance}

{{< kbd "T" >}} 依次切换站点在 `params.ui.preset_menu` 中提供的视觉风格，到最后一种后回到第一种；站点只提供一种风格时不做任何事。{{< kbd "Y" >}} 依次切换浅色、深色和跟随系统三种明暗模式，站点未启用深色调色板（`params.ui.dark_mode` 关闭）时不做任何事。两者在所有交互式页面上有效，并像外观菜单一样记住读者的选择。

### 索引与画廊布局 {#layouts}

在开启 `params.ui.blog_index_toggle` 的博客、发布与案例索引页上，{{< kbd "L" >}} 在列表、卡片、表格和画廊四种布局之间循环。在 [Expo 相册](/zh/docs/write/expo/#shortcuts)页面，以及索引页正在显示[画廊视图](/zh/docs/write/blog/#list-gallery)时，另外三个键控制网格：

| 按键 | 画廊操作 |
| --- | --- |
| {{< kbd ";" >}} | 切换相册模式：展墙、卡片、无缝 |
| {{< kbd "," >}} 或 {{< kbd "<" >}} | 目标图片尺寸缩小 20 px，最小 160 px |
| {{< kbd "." >}} 或 {{< kbd ">" >}} | 目标图片尺寸放大 20 px，最大 360 px |

工具栏随每次按键同步更新，网格立即重排，选择会被记住：Expo 相册使用 `td-expo-mode` 与 `td-expo-size`，索引页画廊使用 `td-blog-gallery-mode` 与 `td-blog-gallery-size`。点击布局图标或拖动尺寸滑杆之后，这些键依然有效。

### 页面宽度 {#page-width}

在宽屏上，即使窗口还有富余空间，正文栏也保持页面原有的宽度。在文档、书籍、博客和 Expo 页面上，{{< kbd "-" >}} 与 {{< kbd "=" >}}（或 {{< kbd "+" >}}）每次把正文栏收窄或加宽 100 px：

- 正文栏最窄 600 px，最宽不超过左右两栏之间的空间。一直加宽到碰到两栏时，正文栏会在任何屏幕尺寸下都铺满这块空间。
- 这个宽度对当前浏览器里本站的所有页面生效，并在首帧之前恢复。它取代各页面的 `page_width` 和书籍的正文宽度，打印时不生效。
- 某一步回到页面自身的宽度时，会停在这个宽度并忘掉保存的值（`localStorage` 中的 `td-shell-article-w`），所以反向按回去，总能让每个页面回到作者设定的宽度。

### Expo 查看器 {#expo-viewer}

Expo 图片会在一个查看器中打开，它有自己的一套按键，用来移动、缩放和切换图片，详见 [Expo 指南](/zh/docs/write/expo/#shortcuts)。查看器打开期间页面快捷键暂停，关闭后恢复。即使关闭了 `keyboard_nav`，查看器按键依然有效。

## 热键说明 {#help}

{{< kbd "'" >}} 在屏幕中央的对话框中列出全部二十九个快捷键：导航、操作、样式三栏并排（十、九、十行）。当前页面无法执行的行仍留在原位，只是变暗显示，屏幕阅读器会读出「暂不可用」，因此这张表在任何页面上都保持同一个形状。对话框在任何位置都能打开：长页面的中段、禅意模式中，或者没有页脚的页面（`footer_style: none`）。再按 {{< kbd "'" >}}、按 {{< kbd "Esc" >}}、点击关闭按钮或点击对话框之外的区域都能关闭它。

页脚最底栏末端的问号按钮提供同一张热键表。鼠标悬停或键盘聚焦到按钮上时，直接在底栏上方展开完整的二十九个快捷键（宽屏三栏并排，窄屏自动折行），当前页面用不上的按键同步变暗；点击按钮则弹出居中模态对话框并附带「启用快捷键」开关，关闭对话框后焦点回到按钮上。

关闭键盘导航但开启本地搜索时，这个按钮只列出命令面板的两个键 {{< kbd "/" >}} 和 {{< kbd `\` >}}，不再打开对话框。

## 保留不绑定的键 {#reserved}

{{< kbd "?" >}} 和数字键刻意保持不绑定，带修饰键的字母保留原有含义，搜索组合键 {{< kbd "Ctrl" "K" >}} 或 {{< kbd "⌘" "K" >}} 除外。标点按键盘布局实际打出的字符识别，例如德语键盘用 {{< kbd "Shift" "7" >}} 打开搜索。画廊和阅读宽度快捷键也接受用 Shift 打出的 `,`、`.`、`;`、`<`、`>`、`=` 和 `+`。

## 快捷键的让行规则 {#stand-down}

每个绑定都是单键，所以凡是可能与文字输入或弹层冲突的场合，它们都会让行：

- 焦点在文本输入控件中：`<textarea>`、`<select>`、`contenteditable`，或文本、搜索、邮箱、密码、数字等需要输入文字的 `<input>`。画廊布局单选按钮、尺寸滑杆等非文本控件仍放行页面快捷键，同时保留各自的方向键操作。
- 焦点在地图或音视频播放器内，这些控件保留自己的按键。
- 输入法正在组字，这对每个中文、日文和韩文站点都很重要。
- 按住了修饰键。{{< kbd "⌘" "C" >}} 仍是复制，{{< kbd "Shift" "M" >}} 不做任何事，{{< kbd "Shift" "↓" >}} 仍归浏览器处理。
- 命令面板、浏览历史、热键说明、Expo 查看器、其他已打开的对话框或可见的 ARIA 对话框占用着键盘。隐藏的 ARIA 对话框不会阻止快捷键。

评论区在 iframe 中加载，其中的按键不会传到页面。

## 焦点顺序与无障碍 {#a11y}

- **跳转链接**：进入页面后第一次按 {{< kbd "Tab" >}} 出现「跳转到主要内容」，一步越过顶部导航栏和侧栏，并标出文章标题。
- **真实焦点**：侧栏导航移动的是真正的 DOM 焦点，屏幕阅读器因此读出链接名称和「当前页」状态，{{< kbd "Enter" >}} 保持链接的原生行为，Tab 顺序不变。
- **隐藏内容**：折叠的侧栏或关闭的抽屉退出 Tab 顺序，用来恢复它们的按钮仍可到达。点击正文、表格或代码块之后，再按其他键也不会留下大面积的焦点框。
- **高对比度**：在 `forced-colors` 模式下，焦点行和选中的历史条目改用系统高亮色描边。
- **减弱动态效果**：开启 `prefers-reduced-motion` 时，锚点跳转和翻页立即到位，不做滑动。
- 热键说明中的键帽与正文中使用的[按键](/zh/docs/components/kbd/)组件是同一套样式。

## 关闭 {#disable}

读者可以打开热键说明，取消勾选默认开启的「启用快捷键」。也可以从页面开头按 Tab，经过「跳转到主要内容」后，
再按一次 Tab 到达同一个开关，按空格即可关闭或重新启用。没有页脚的页面也可这样操作。
浏览器为本站的所有语言记住这项选择。Ctrl+K 或 ⌘K 仍可打开搜索面板。

全站关闭：

```yaml {title="hugo.yml"}
params:
  ui:
    keyboard_nav: false
```

只关闭某一页，例如交互密集的演示页，或通过 `cascade` 关闭整个分区：

```yaml {title="content/docs/playground.zh.md"}
---
title: 交互演练场
keyboard_nav: false
---
```

这个键只接受布尔值，完整定义见[配置总览](/zh/docs/customize/config/)。关闭键盘导航的页面完全不加载键盘运行时：没有快捷键，不记录浏览历史，也不恢复页面宽度。{{< kbd "/" >}}、{{< kbd `\` >}} 和 {{< kbd "⌘" "K" >}} 属于搜索，仍然有效；页脚的折叠箭头不受影响。

## 验证 {#verify}

先构建站点，再把下面的 `public/zh/docs/getting-started/index.html` 换成站点实际生成的某个文档页，并按语言配置调整路径前缀。

1. 确认帮助按钮在页面中：

   ```bash
   hugo --printPathWarnings
   PAGE=public/zh/docs/getting-started/index.html
   test -f "$PAGE" && grep -c 'td-shell-keyboard__trigger' "$PAGE"
   ```

   关闭键盘导航且没有开启本地搜索时，这个按钮不会生成。

2. 打开一个文档页并按 {{< kbd "'" >}}：出现三栏列表，本页不具备的功能变暗显示。再按一次关闭对话框。
3. 焦点停在正文时连按几次 {{< kbd "S" >}}：侧栏焦点从当前页开始逐项下移，正文保持不动。再按 {{< kbd "E" >}}，确认翻页顺序与侧栏一致。
4. 先读两个页面，再按 {{< kbd "H" >}} 和 {{< kbd "Enter" >}}：你会回到第一个页面。
5. 连按两次 {{< kbd "O" >}}：侧栏章节全部展开，随后除当前页所在分支外全部折叠。
6. 在宽窗口中按 {{< kbd "=" >}} 和 {{< kbd "-" >}}：正文栏随之加宽和收窄，刷新后保持宽度。
7. 点进搜索框再按 {{< kbd "J" >}}：字母正常输入，页面不滚动。用输入法再试一次。
