OINK 的交互式页面自带一套单键快捷键：WASD 在侧栏树中移动，{{< kbd "K" >}} {{< kbd "J" >}} 在标题间跳转，{{< kbd "Q" >}} {{< kbd "E" >}} 翻页，{{< kbd "H" >}} / {{< kbd "Z" >}} 切换禅意模式，{{< kbd "V" >}} 切换索引布局，{{< kbd "M" >}} 与 {{< kbd "," >}} / {{< kbd "." >}} 控制 Expo 与画廊视图，{{< kbd "L" >}} / {{< kbd "X" >}} / {{< kbd "T" >}} / {{< kbd "Y" >}} / {{< kbd "R" >}} 切换语言、外观与栏目，{{< kbd "F" >}} / {{< kbd "C" >}} 打开命令面板，{{< kbd ";" >}} 弹出热键说明。默认开启，对文本输入与弹层让行，可按站点或按页面关闭。

键盘导航不维护第二套状态：树的展开折叠复用侧栏原有的箭头按钮，逐节跳转读取右栏目录，切换语言与主题复用命令面板的同一批动作。键盘操作的顺序与鼠标操作的顺序因此一致。

## 侧栏 {#sidebar}

| 按键 | 行为 |
| --- | --- |
| {{< kbd "W" >}} {{< kbd "S" >}} {{< kbd "↑" >}} {{< kbd "↓" >}} | 焦点移到上一个 / 下一个可见项 |
| {{< kbd "A" >}} {{< kbd "D" >}} {{< kbd "←" >}} {{< kbd "→" >}} | 折叠 / 展开分组；叶子节点上 {{< kbd "A" >}} 跳到父级，{{< kbd "D" >}} 无动作 |
| {{< kbd "Enter" >}} {{< kbd "Space" >}} {{< kbd "G" >}} | 激活焦点所在的项：打开页面链接，或展开/折叠分组按钮 |
| {{< kbd "Esc" >}} | 退出树，焦点回到正文 |

四个字母键不需要先进入树：焦点还在正文时按 {{< kbd "S" >}}，以当前页在侧栏里的那一项为起点下移一格并落焦。焦点行整行加深底色，比「当前页」的底色深一档，用于区分当前页与焦点位置。

窄屏侧栏收进抽屉、或桌面侧栏被折叠时，第一次按这四个键先展开侧栏。页面没有侧栏树时静默。

方向键 **只在焦点已经进入侧栏后** 才作用于树，正文里保持浏览器原生滚动。RTL 语言下 {{< kbd "←" >}} {{< kbd "→" >}} 随阅读方向对调，{{< kbd "A" >}} {{< kbd "D" >}} 恒等于「折叠 / 展开」。

自 OINK 1.1 起，不发布自身页面的分组通过展开按钮参与导航。从子页按 {{< kbd "A" >}}
先回到父分组，再按一次才折叠；{{< kbd "D" >}} 展开已折叠的分组，已展开时进入第一个
可见子项。{{< kbd "Q" >}} / {{< kbd "E" >}} 翻页会跳过分组按钮。

## 阅读 {#reading}

| 按键 | 行为 |
| --- | --- |
| {{< kbd "K" >}} | 沿页面目录跳到上一个标题 |
| {{< kbd "J" >}} | 沿页面目录跳到下一个标题 |
| {{< kbd "N" >}} | 首页专用：跳到下一个顶层分区（首页 {{< kbd "J" >}} 的助记别名） |
| {{< kbd "Q" >}} {{< kbd "E" >}} | 上一篇 / 下一篇 |
| {{< kbd "H" >}} {{< kbd "Z" >}} | 禅意模式（Zen Mode）：隐藏 / 恢复导航外壳 |
| {{< kbd "B" >}} | 站点开启 `params.ui.compare` 且本页有译文时，打开或关闭[双列视图](/zh/docs/customize/i18n/#bilingual-view) |

{{< kbd "K" >}} 与 {{< kbd "J" >}} 的目标序列与右栏目录同源，落点与点击目录一致。跳转是固定 100 ms 的缓动滑行，与距离无关；连续按键不必等上一段动画结束。已经读到某一节内部一段距离后，{{< kbd "K" >}} 先回到本节起点，再按一次才跳到上一节。页面没有标题时退化为一小段滑动。

{{< kbd "Q" >}} {{< kbd "E" >}} 按 **侧栏树的可视顺序** 翻页，不按日期。栏目入口页本身也是树里的一项，博客的栏目边界因此表现为「上一专栏最后一篇 → 下一专栏入口页 → 下一专栏第一篇」。折叠起来的分支不在这个顺序里：翻页顺序与焦点移动顺序是同一个。页面没有侧栏树时回退到页尾翻页器，没有翻页器时用 `<head>` 里的 `rel=prev/next`。

{{< kbd "H" >}} 和 {{< kbd "Z" >}} 在首页只隐藏顶栏与页脚，在文档页同时隐藏左右栏与浮动按钮。状态记录在当前标签页的会话中，首帧之前恢复，用 {{< kbd "Q" >}} {{< kbd "E" >}} 连续翻页不丢状态、不闪烁。外壳隐藏时 WASD 不会把焦点送入不可见的侧栏。

## 外观、语言与路由 {#appearance}

| 按键 | 行为 |
| --- | --- |
| {{< kbd "V" >}} | 在开启 `blog_index_toggle` 的博客、发布或案例导航页中切换布局（列表、卡片、表格、画廊） |
| {{< kbd "L" >}} {{< kbd "X" >}} | 循环切换语言 |
| {{< kbd "T" >}} | 按顺序循环切换视觉风格（Paper、Slate、Ink、Terminal） |
| {{< kbd "Y" >}} | 在浅色、深色、系统三种明暗模式之间循环切换 |
| {{< kbd "R" >}} | 切换栏目：在首页与顶栏的同源一级入口之间循环 |
| {{< kbd ";" >}} | 打开或关闭热键说明对话框 |

{{< kbd "L" >}} / {{< kbd "X" >}}、{{< kbd "T" >}}、{{< kbd "Y" >}}、{{< kbd "R" >}} 与 {{< kbd ";" >}} 在任何交互式页面上都有效，不限于阅读外壳。{{< kbd "V" >}} 仅在渲染了布局切换按钮（`blog_index_toggle: true`）的导航索引页生效。单语言站点的 {{< kbd "L" >}} / {{< kbd "X" >}}、站点未提供风格选择（`preset_menu`）时的 {{< kbd "T" >}}、关闭明暗菜单后的 {{< kbd "Y" >}}、只有一个一级入口时的 {{< kbd "R" >}} 都静默。{{< kbd "T" >}} 到最后一种风格后回到第一种，{{< kbd "Y" >}} 按浅色 → 深色 → 系统顺序循环。{{< kbd "R" >}} 只在同源的一级菜单项之间循环，外链与顶栏上的工具控件不参与。{{< kbd ";" >}} 会在浏览器顶层居中弹出当前页可用的双列热键说明对话框——无论当前滚动位置、处于禅意模式，还是页面设置了 `footer_style: none` 均可打开；再按一次 {{< kbd ";" >}}、按 {{< kbd "Esc" >}}、点击关闭按钮或点击遮罩层即可关闭。点击页脚最底层栏的 `?` 按钮会打开同一个居中弹窗，桌面端悬停或聚焦 `?` 则会在底栏上方直接预览双列速查卡。

## 搜索与命令 {#search}

| 按键 | 行为 |
| --- | --- |
| {{< kbd "F" >}} 或 {{< kbd "/" >}} | 打开命令面板的完整搜索态 |
| {{< kbd "C" >}} 或反斜杠键 | 打开命令面板的纯命令态 |
| {{< kbd "⌘" "K" >}} 或 {{< kbd "Ctrl" "K" >}} | 打开面板；再按一次关闭 |

{{< kbd "/" >}} 和反斜杠属于搜索功能本身，关闭键盘导航后仍然可用；{{< kbd "F" >}} {{< kbd "C" >}} 是键盘导航提供的别名，指向同一个面板实例。部分非美式键盘布局上反斜杠不易按到，在面板里输入 `>` 前缀同样进入纯命令态。面板里有什么见[命令面板](/zh/docs/customize/panel/)。

## Expo 与画廊控制 {#expo-viewer}

在单个 [Expo 相册](/zh/docs/write/expo/#shortcuts)页面（非相册总览目录页），或在博客／案例／发布导航索引页切换到[画廊（`gallery`）视图](/zh/docs/write/blog/#list-gallery)后（可先按 {{< kbd "V" >}} 切换至 `gallery`），页面级键盘导航还提供画廊布局与图片大小快捷键：

| 按键 | 画廊网格中的操作 |
| --- | --- |
| {{< kbd "M" >}} | 切换画廊布局模式（展墙 → 卡片 → 无缝） |
| {{< kbd "," >}} 或 {{< kbd "<" >}} | 缩小目标图片尺寸一档（`−20 px`，最低 `160 px`） |
| {{< kbd "." >}} 或 {{< kbd ">" >}} | 放大目标图片尺寸一档（`+20 px`，最高 `360 px`） |

两组操作都会同步更新工具栏状态、立即重排网格，并持久化保存在 `localStorage`（Expo 相册使用 `td-expo-mode` / `td-expo-size`，博客／案例／发布画廊使用 `td-blog-gallery-mode` / `td-blog-gallery-size`）。点击布局单选按钮或拖动尺寸滑杆后，这些快捷键依然可用。

[Expo 查看器](/zh/docs/write/expo/#shortcuts)使用独立的快捷键。
打开图片时，页面单键导航暂停；关闭后恢复。

| 按键 | 查看器中的操作 |
| --- | --- |
| W / A / S / D | 将放大后的图片向上／左／下／右移动 |
| Q 或 H、E 或 L | 上一张、下一张 |
| J 或 −、K 或 + | 缩小、放大 |
| R 或 0 | 重置尺寸和位置 |
| F | 放大至适屏，完整容纳图片 |
| Escape | 关闭查看器 |

画廊网格快捷键受 `keyboard_nav` 控制；查看器内操作仅在查看器内部生效，不受 `keyboard_nav: false` 影响。Expo 随 OINK 1.3.0 提供。

## 保留不占用的键 {#reserved}

{{< kbd "?" >}} 保留不绑定。在页面任意位置按 {{< kbd ";" >}}，或点击页脚最底层栏的问号按钮，即可弹出居中的双列热键说明对话框；桌面端（`≥ 768 px`）将鼠标悬停或键盘聚焦到问号按钮上，也会在底栏上方直接预览同一份双列速查卡，而关闭弹窗归还焦点时不会误触发悬停弹层。关闭 `keyboard_nav` 且开启本地搜索时，该按钮保留紧凑的单列搜索快捷键浮层。两者都只列出当前页面实际可用的按键，单语言站点看不到切换语言那一行。

{{< kbd "G" >}} {{< kbd "G" >}}、{{< kbd "Shift" "G" >}} 和数字键同样保留，可能用作将来的跳转序列。

## 快捷键的让行规则 {#stand-down}

每条绑定都是单键快捷键，凡是可能和文本输入或弹层冲突的场合一律禁用：

- 焦点位于文本输入控件中（`<textarea>`、`<select>`、`contenteditable`，或文本、搜索、邮箱、密码、数字等输入型 `<input>`）。画廊布局单选框、图片尺寸滑杆等非文本控件仍放行页面快捷键，同时保留各自原生的方向键操作；
- 正在用输入法组字（中文站的硬约束）；
- 按住修饰键时——唯独 {{< kbd "<" >}}（`Shift+,`）与 {{< kbd ">" >}}（`Shift+.`）因标准键盘需要按住 {{< kbd "Shift" >}} 而放行 `Shift`：{{< kbd "⌘" "C" >}} 仍是复制，{{< kbd "Shift" "M" >}} 不触发，{{< kbd "Shift" "↓" >}} 仍归浏览器；
- 命令面板、其他已打开的原生对话框（包括 `;` 热键说明对话框或 Expo 查看器）或可见的 ARIA 对话框占用键盘。固定定位的 ARIA 对话框同样会阻止快捷键，隐藏的 ARIA 对话框则不会。

评论区在 iframe 中，键事件不冒泡到页面，无需额外隔离。

## 焦点顺序与无障碍 {#a11y}

自 OINK 1.1 起，隐藏的侧栏与抽屉内容退出键盘焦点范围。鼠标点击正文、表格
滚动区或代码块后，再按其他键不会出现大范围边框。键盘焦点仍清晰可见：跳转链接在
文章标题附近显示焦点提示，可滚动的表格和代码保留自己的焦点提示与键盘滚动能力。

- **跳转链接**：进入页面后第一次按 {{< kbd "Tab" >}} 出现的就是「跳转到主要内容」，一步跳过顶栏和侧栏。
- **真实焦点**：树内导航移动的是真正的 DOM 焦点，不是虚拟光标。屏幕阅读器因此读出链接名与「当前页」标记，{{< kbd "Enter" >}} 是链接的原生行为，Tab 顺序没有被改写。
- **高对比度**：焦点行的底色在 `forced-colors` 模式下失效，退化为系统高亮色描边。
- **减弱动效**：`prefers-reduced-motion` 打开时，逐节跳转与翻页滚动改为瞬时定位，不做滑行。
- 速查卡里的键帽与正文里的[按键](/zh/docs/components/kbd/)组件是同一套样式。

## 关闭 {#disable}

全站关闭：

```yaml {title="hugo.yml"}
params:
  ui:
    keyboard_nav: false
```

单页关闭（交互密集的演示页常常需要），或者用 cascade 按整节关闭：

```yaml {title="content/docs/playground.zh.md"}
---
title: 交互演练场
keyboard_nav: false
---
```

这个键只接受布尔值。写成 `"false"` 或其它非布尔值时会报 `params.ui.keyboard_nav must be a boolean` 告警并使用站点默认值。完整定义见
[配置总览](/zh/docs/customize/config/)。

关闭后运行时不进入 JavaScript bundle，而不是加载后再判断。{{< kbd "/" >}}、反斜杠和 {{< kbd "⌘" "K" >}} 属于搜索，仍然可用；页脚折叠链接栅格的箭头不受影响。

## 验证 {#verify}

先在自己的站点根目录完成生产构建。下方命令中的
`public/zh/docs/getting-started/index.html` 是示例；请换成自己站点实际生成的文档页，
并按语言配置调整路径前缀。

1. 构建后确认速查卡按钮在页面里：

   ```bash
   hugo --printPathWarnings
   PAGE=public/zh/docs/getting-started/index.html
   test -f "$PAGE" && grep -c 'td-shell-keyboard__trigger' "$PAGE"
   ```

   关闭键盘导航且没开本地搜索时，这个按钮整个不生成。

2. 打开一篇文档，光标停在正文里连按 {{< kbd "S" >}}：侧栏里应该从当前页那一项开始逐项下移，正文不动。

3. 按 {{< kbd "E" >}} 若干次，核对翻页顺序与侧栏从上到下的顺序一致；折叠一个分组再翻，被折叠的页面应该被跳过。

4. 点进搜索框，按 {{< kbd "J" >}}：页面 **不应该** 滚动，字符正常输入。使用中文输入法输入时同理。

5. 系统里打开「减弱动态效果」，再按 {{< kbd "J" >}}：应该瞬间定位，没有滑行。

6. 在页面滚动到中段或进入禅意模式（{{< kbd "H" >}} / {{< kbd "Z" >}}）时按 {{< kbd ";" >}}，并在页脚悬停再点击 `?` 按钮：确认桌面端悬停展示双列速查卡，点击 `?` 或按 {{< kbd ";" >}} 打开居中双列弹窗，关闭后归还焦点且不再误弹悬停卡片。

7. 打开任意 Expo 相册，或在 `/zh/blog/` 按 {{< kbd "V" >}} 切到 `gallery` 视图，再依次测试 {{< kbd "M" >}}、{{< kbd "," >}} / {{< kbd "<" >}} 与 {{< kbd "." >}} / {{< kbd ">" >}}（包括点击布局图标或拖动滑杆之后）：确认网格立即重排并跨刷新记住选择。

8. 验证 1.1 的焦点修复时，先通过跳转链接进入正文，检查标题附近的焦点提示；再折叠
   侧栏并按 {{< kbd "Tab" >}}，隐藏的链接应被跳过，恢复按钮仍然可以到达。
