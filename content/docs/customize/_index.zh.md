| 首页与落地页 | [首页与落地页](/zh/docs/customize/home/) |
| 全文检索与索引范围 | [全文检索](/zh/docs/customize/search/) |
| 命令面板里的条目 | [命令面板](/zh/docs/customize/panel/) |
