## Tab 评审修订 {#tab-review}

维护者不接受凸起的选中标签。最终样式让单个标签平时背景透明，仅在支持悬停的设备上显示淡底色，以链接色和 2px 底边线标识选中。文字保持相同的中等字重和位置；键盘焦点另有轮廓，粗指针设备的点击目标高度仍至少为 44px。最终引擎复核检查了这些状态、方向键切换和窄屏布局。

## 参数名与最终修正 {#final-corrections}

Terminal 参数名现在与其他预设一致，使用无边框的加重等宽文字。原生 Markdown 表格和完整 Fields 短代码均检查了中英双语与明暗输出。正文中的普通行内代码与按键边框保留各自的表达作用。

最终评审还复现并修正了两个边界问题：

- 原生卡片的整卡标题链接会拦截嵌在强调文字中的次级链接。现在次级控件保持在整卡目标之上，指针检查确认嵌套链接和卡片其余区域均跳转正确。标题的键盘焦点轮廓沿用卡片自身形状。
- 禁用 JavaScript 后，命令条仍保留一小列空白操作区域。现在复制控件可用之前，其包装容器保持隐藏。在三个引擎中，390px 样例的源码列均占满 356px 内部宽度，启用脚本后的复制控件仍正常可用。

## 基线失败与限制 {#limits}

以下两项主题检查在导出的基线和组件候选中完全相同地失败：

- `check-namespace.py`：已提交的博客画廊使用无前缀的 `data-height`、`data-width`、`data-mode`、`data-size`，并读取对应的无前缀 dataset 属性。
- `check-goldens.py`：现有主题快照尚未包含已提交画廊的首屏初始化条件、工具栏图标与画廊标记。用检查器自身的规范化规则对比基线和候选，全部 52 个快照表面均无新增差异。

这些是已有的画廊问题，因此不能声称仓库级检查全部通过。其断言与快照未被放宽。组件检查器另有一处必要修正：按配置键识别已移除功能，避免把任何 `gallery` 字样都当作旧功能，允许合法的 `blog_gallery` 配置。

本地验收覆盖本轮组件修改和两项最终修正。Ink 与 Terminal 保持实验状态。运行时 JavaScript 未修改，因此未重跑其单元套件。本任务没有推送提交、打 tag、发布版本、升级消费站或部署。
