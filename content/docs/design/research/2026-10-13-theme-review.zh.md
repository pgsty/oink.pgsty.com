## 范围 {#scope}

审查开始时主题位于 `f8f476e`，共享工作树中已有下游站点维护、紧凑侧栏修改，以及进行中的英文文档修订。这些工作均被保留。审查期间，原有侧栏修复被单独提交为 `8f1f08d`，对应文件内容未发生变化。

本次覆盖主题自有检查器、运行时单元测试、合成输出夹具、真实双语文档站，以及两类下游站点：DDIA 图书和 SILO 大型文档树。源码检查重点包括 URL 处理、图片输出、消息边界、焦点切换、运行时隔离与导航。视觉检查使用真实下游页面和文档站。

## 已复现缺陷与修复 {#repairs}

| 缺陷 | 触发方式与表现 | 修复与回归 |
| --- | --- | --- |
| 图片 URL 逃出 HTML 属性 | 普通图片或 Gallery 的 URL 中，引号后跟属性形状的查询值，会生成额外 HTML 属性；与号也可能改变浏览器解码后的 URL。 | URL 校验后再做 HTML 属性转义。`check-media-primitives.py` 解析 HTML、Print、RSS 中块级和行内图片属性；`check-gallery.py` 检查含引号的 Gallery URL。无执行代码的额外属性探针在修复前失败。 |
| Draw.io 丢失端点参数且消息处理不严谨 | 已有查询参数或片段的端点被拼接成错误的嵌入地址。空值或异常消息可能抛错，处理消息时也没有要求配置的源。 | 使用 `URL` 和 `searchParams` 构造地址；核对当前 iframe 与配置的源；忽略异常数据；向确切源发送消息，仅接受 PNG/SVG 图片导出 URL。新增 Draw.io 单元测试与站点编辑器集成测试覆盖这些路径。 |
| 页面操作菜单的键盘行为不完整 | ArrowDown 打开菜单时，CSS 可见性过渡尚未允许焦点进入；Tab 离开菜单后菜单仍保持展开。 | 可见性立即切换，保留透明度和位移动画；焦点离开整个控件后关闭菜单，且不抢回焦点。运行时和真实浏览器测试覆盖正向、反向遍历。 |
| 外观面板重开后被旧事件清除状态 | 在原生 `close` 事件排队期间立即重开面板，面板仍可见，`aria-expanded` 却变成 false。 | 面板已经重新打开时忽略此前的关闭事件。真实浏览器测试在 Chromium、Firefox、WebKit 的桌面与手机宽度覆盖该竞态。 |

两份分类页 HTML 快照也需要跟进已有侧栏修复：完整核对差异后，每份移除了 33 处错误的叶节点隐藏标记。随后 52 个输出面的快照检查通过。

相关行为已经写入双语 [架构](/zh/docs/design/architecture/) 与 [外壳](/zh/docs/design/shell/) 契约。此次修改无需配置迁移，也没有新增依赖。

## 性能观察 {#performance}

检查了文档站严格构建、压缩后的本地 production 输出。`/docs/customize/config/` 引用的本地 JavaScript 合计 **62,192 字节 gzip**（约 61 KiB，含 Lunr）；两个样式表合计 **98,838 字节 gzip**（约 97 KiB），不含字体、图片、搜索索引和第三方服务流量。

普通文档页未包含大型图表包。Mermaid 样本额外加载 **976,006 字节 gzip** 的 Mermaid 依赖（约 953 KiB）以及小型页面运行时。运行时隔离与输出检查通过。
