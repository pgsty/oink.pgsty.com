> [!NOTE] OINK 1.2.0
> Paper 与 Slate 已随 1.2.0 发布。Ink 与 Terminal 作为显式启用的风格一同提供，
> 后续设计工作见下文记录。

## 决策 {#decision}

Paper 成为默认，使用暖纸色与墨色、蓝色链接、IBM Plex Sans、标题细线和外框
表格。Slate 保留 v1.1.0 色板、Inter/Chakra/Plex Mono 字体角色与 Landing 网格、
光晕。这样为阅读站点提供更安静的默认外观，同时保留明确的兼容选项。代价是默认
外观发生可见变化：原站点可设置 `params.ui.preset: slate`。1.2.0 发布注记与升级指南已醒目说明此变化。

读者菜单默认关闭（`preset_menu: false`），文档站开启。一个外观入口包含原生
风格与明暗单选组，手机通过浏览器顶层模态 dialog 显示底部表单。触屏和键盘无需
悬停即可使用。代价是原来单击即切明暗变成选择面板；`t` 快捷键仍可直接切换明暗。

风格与明暗使用不同的属性和存储键。选择站点默认预设清除风格键。Hugo 在无
JavaScript 时输出默认值，白名单内联脚本在 CSS 前恢复读者选择，避免初始预设
不一致；禁用存储时仍可操作。预设共用一个样式表，代价是增加少量 CSS。

`brand` 将字标与展示标题分开。Paper 新增本地 OFL IBM Plex Sans 可变字体，包含
正体、斜体和六个小型文字系统子集，按实际使用下载。系统排版与显式字体角色覆盖
仍优先，中文使用系统栈。第一阶段不加入衬线字体，不新增外部字体请求。

密度由页面任务决定：首页保留展示尺度，长文保留阅读行宽，导航与参数表保持紧凑。
不统一扩大间距，不引入第二套外壳或几何抽象。Giscus 和打印跟随预设，API 供应商
组件与图表保持现有的明暗行为，以此约束第一阶段范围。

## 后续工作 {#later-work}

2026-10-24，维护者决定移除 Paper 标题右侧的尾随细线，减少视觉干扰。OINK 1.4.0 的实现
在浅色与深色模式下均移除这条线，保留标题字体与锚点。此修订随 OINK 1.4.0
发布；上文的 1.2.0 决策保留当时的外观记录。

10 月 5 日随后开展的实验在显式配置后提供 Ink 与 Terminal，见
[实验记录](/zh/docs/design/research/2026-10-05-ink-terminal-experiment/)。两者尚未成为
稳定默认选项。`preset_menu: true` 提供 Paper/Slate 与站点默认值；显式列表可以
展示实验。四种风格共用简洁的图标与名称按钮，不另加实验标记。这样可用真实主题
输出评审，同时保留普通菜单的
选项范围，代价是额外的局部 CSS，以及开启实验后更大的菜单。

实验以主题自有组件规则实现直角/2 px 圆角与紧凑桌面导航，不引入全局密度框架。
复用现有本地字体、状态管理与无障碍控件。图表和 API 供应商组件仍只随明暗变化，
评论色板与打印跟随实验预设。剩余工作是视觉定稿、更广设备评审，以及是否晋升为
稳定选项的决定。

2026-11-26，维护者要求对四套预设做一轮打磨，并让复制的段落能干净地粘贴到富文本
编辑器。Paper 的画布改为象牙色 `#faf9f5` 并获得陶红强调色：此前偏灰的画布与链接蓝
强调色让 Paper 过于接近暖色版的 Slate；链接保持蓝色，深色 Paper 保留原画布。代价是
未设置 `theme_color` 的 Paper 站点强调色会发生可见变化。Slate 色板保持冻结。Ink
标题降为 700 字重，即平台中日韩字体的最大字重，章节横线为 1 像素。Terminal 的标题
标记改为较轻的字重并拉开间距，使井号保持可辨。所有预设为裸 `<kbd>` 增加键帽样式，
降低列表符号的墨色，并在中日韩段落中将标题字距归零。同日的第二轮确定了阅读质感：Paper 与 Ink 的链接从半粗体改为
与正文同字重的下划线，因为一段里的几个粗体链接读起来像作者并未写下的强调；Slate 与
Terminal 保留半粗体线索。Paper 与 Terminal 的行内代码降为 400 字重，不再与作者的加粗
争夺注意力。`v` 键在可选预设间依次切换，`y` 键切换明暗，不再切换语言。2026-11-27，维护者
接受了每套预设的中文字体方案：四套风格的西文各有声音，汉字却都落在同一款平台黑体上。
现在每套预设用读者已有的字体以不同方式编排宋、黑、楷：Paper 为宋体标题配黑体正文，
Ink 为黑体标题配宋体正文，Slate 保持黑体，Terminal 正文使用等宽。楷体用于强调与引用。
代价是西文也随之改变，因为宋体旁要配衬线：Paper 的标题与 Ink 的正文改用系统衬线，
Terminal 的正文改用等宽。因体积过大，否决了内置中文网页字体。Windows 与 Android 上的
渲染尚未验证。同日的快捷键收口确定了最终键位：`t` 循环切换可选视觉预设，`y` 在浅色、深色与系统三种明暗模式间循环，`l` 用于博客／发布／案例索引页的布局切换，`v` 切换站点版本。排版复制复用打印色板，不新增
第三套色板，行为由[架构契约](/zh/docs/design/architecture/#typeset-copy)规定。这些
变更随 OINK 1.7.0 发布。

2026-11-28，维护者认定 1.7.0 对 Paper 的刷新是一次回归：使用默认预设的读者没有改动
任何设置，看到的页面却变了样。Paper 回到 1.6.0 的样子：画布 `#f7f6f3`、墨色
`#21201c`，标题用 IBM Plex Sans 配平台黑体，强调色重新采用链接蓝，正文链接恢复
半粗体，行内代码恢复原有字重，引用左侧恢复细线，打印、排版复制与评论区色板也回到
1.6.0。所有预设共用的排版保持不变：汉字强调用直立楷体，键帽样式、较淡的列表符号、
等宽数字以及中日韩标题零字距。1.7.0 的样子没有丢弃，而是保留为实验预设 News。
它参照 Typora 的 Newsprint 主题，排成一栏印刷版面：沿用象牙色板与陶土色强调，正文和
标题都用衬线，汉字用宋体，引用用楷体；标题用正文字重，下方加双线；表格敞开，上下各
一条墨线；西文引用用斜体，链接带下划线。导航、搜索与菜单仍用界面无衬线字体，因为
宋体在控件字号下笔画过细。另一项实验 GitHub 按 GitHub 渲染 README 的方式还原
Markdown，浅色与深色兼备。数值取自 github-markdown-css 5.9.0 与
@primer/primitives 11.10.0，二者均为 MIT 许可。为满足对比度，三个数值有所调整：
深色主按钮悬停色改为 `#268838`；浅色选中标签页下划线用 `#bc4c00`，替代对比度仅
2.15:1 的珊瑚色；深色焦点环沿用链接蓝。汉字强调保留 OINK 的楷体，不用倾斜的无衬线。
风格菜单随六套预设调整：只要提供风格选项，触发按钮就显示调色板；三、五或六套预设排成
三列，与下方三个明暗卡片对齐；启用键盘导航时，两个分组标题分别注明 `t` 与 `y` 键。
`folio` 与 `canvas` 继续保留。代价是已经采用 1.7.0 的站点会看到 Paper 变回原样，
可以改选 `news`。这些变更随 OINK 1.8.0 发布。

同日稍晚，维护者要求再做一轮调整。衬线预设更名为 News，菜单顺序为 Paper、Slate、
GitHub 在上，Ink、News、Terminal 在下。每套预设的深色模式都应带来独立的体验：字体
沿用浅色模式，色系各自发挥。深色 Terminal 成为一块荧光屏，取电影里绿色代码雨的意象：
黑底绿字，标题与链接发光，带淡淡的扫描线，语法高亮为单色绿。深色 Ink 是一张碑拓，
青黑底上写宣纸色的字，配朱砂印；深色 News 是烛光下的夜报，暖褐底上的羊皮纸色文字
与金色链接。Paper、Slate 与 GitHub 保留原有深色色板：Paper 刚刚恢复原样，Slate 的
色板已冻结，GitHub 以还原 GitHub 为准。Ink 改写为笔墨书写的页面：汉字标题用楷体、
正文用宋体，西文用 Palatino，一款源自文艺复兴笔写字母的罗马体。页面标题用正文字重，
每节开头有一道收锋的笔触，`hr` 是一笔短画，引用挂在一道渐淡的朱砂笔触上。原先的
深红强调色改为印泥红，并去掉瑞士风格的大写标签。`OINK Kai` 新增一组只引用已安装
粗楷体的粗体字体，楷体标题因此显示真正的粗体。主题仍不分发字体文件；没有 Palatino
或楷体的系统回退到系统衬线与宋体。这些变更随 OINK 1.8.0 发布。

当晚的第三轮按照[Ink 与 News 提案](/zh/docs/design/proposals/ink-news-presets/)把两套纸面预设
分开：Ink 是写出来的页面，News 是印出来的页面。Ink 改用暖色纸 `#f3ead7`，纸面向窗口
边缘渐深，以墨色 `#241a10` 与朱色 `#a8321b` 为两种墨。中文正文通过新增的 `local()`
别名 `OINK Fangsong` 使用仿宋，未安装时回退到宋体；页面标题的西文用书写体（Apple
Chancery、Gabriola 或 URW Z003），汉字用楷体；所有标题都用正文字重，章节标题用
Palatino 斜体。中文 `strong` 改为朱色着重号，Blog 与 Book 正文以朱色首字开篇，导航
当前行加朱色圆点，页头字标框成印章。深色 Ink 由碑拓改为紫青色绀纸 `#1b1730` 上的
金银字，因为碑拓近乎中性的黑底与 Paper 的深灰太接近。News 改用灰色新闻纸
`#f0eee8`、油墨黑与一种专色蓝 `#1f4f7a`，去掉与 Ink 朱色难以区分的陶红。标题改用
粗重的 Times New Roman 配宋体-简 Black，标题下有副题与大写日期线，每节上方一道粗细
双线，引用为上下加线的拉引，页头下缘一道报头双线，没有圆角与阴影。深色 News 由烛光
夜报改为暗房：`#0f0f0f` 上的银盐色文字配安全灯橙 `#f2804a`，因为羊皮纸与金色现在归
Ink。`check-presets.py` 另在渐变画布的极值 `--td-preset-canvas-edge` 上检查文字对比度。
提案中有三项没有实现：日文与韩文的分语言字体栈，因为预设的字体角色只写在根元素的
裸选择器上，`typography: system` 与 `params.ui.fonts` 才能继续覆盖它们；标题上方的
眉题，需要新增标记；Blog 列表的分栏，因为列表在运行时于三种形态之间切换。代价是
1.7.0 中选用 `ink` 的站点外观会明显改变。这些变更随 OINK 1.8.0 发布。

当晚维护者在文档站上审阅三套预设后，又做了一轮校准。Ink 去掉书写体与印章：首页上的
Apple Chancery 读起来像装饰而不是文字，字标外的红框也是多余的标记。Ink 现在全页一种
声音，西文处处用 Palatino，汉字在标题与界面中用楷体，正文仍用仿宋；展示角色即标题
字体。News 的界面、菜单与列表改用正文衬线字体而不是 IBM Plex Sans，界面部件改为直角，
整页读起来像同一张印刷版面。深色 Terminal 原先把整个屏幕都染成绿色，正文、界面与代码
难以区分；现在正文与界面回到浅灰绿，荧光绿只留给标题、链接与当前行的光标条，标题标记
与引用竖线改用琥珀色，代码恢复多种色相。外观按钮重新显示读者的明暗选择，即太阳、月亮
或表示跟随系统的半实心圆，不再显示调色板；明暗分组的英文标题改为 Color。Paper、Slate
与 GitHub 不变。这些变更随 OINK 1.8.0 发布。

## 依据 {#evidence}

2026-10-25，维护者授权在既有四种预设中精修组件。共用表面、分组行、稳定文字和
仅背景移动的按压反馈，均复用现有变量与 CSS。Markdown 仍是主要写作方式，三个
本地呈现变体均需显式启用。Paper/Slate 保留圆润表面，Ink/Terminal 保留扁平与
直角／2px 几何。滑动选中背景试验暂缓：静态状态已经提供所需反馈，无需额外位置
测量或运行时层。这些修改随 OINK 1.4.0 发布；支持的写法与回退行为归属
[组件契约](/zh/docs/design/components/#component-refinement)。

[架构契约](/zh/docs/design/architecture/#visual-presets)与
[外壳契约](/zh/docs/design/shell/#appearance-control)管理当前行为。
`check-presets.py` 管理 token 对称、AA 色板、冻结的 Slate v1.1.0 色板及严格配置
输出。字体、参数、vendor、命名空间、动作与运行时检查继续沿用原归属。文档站的
`appearance.spec.mjs` 检查真实输出；[带日期验收记录](/zh/docs/design/research/2026-10-05-visual-presets-acceptance/)
区分已执行检查与后续实验。
