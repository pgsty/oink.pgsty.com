> [!NOTE] 已随 OINK 1.7.0 发布
> 这套键位表、本地历史、全部折叠、读者宽度与读者单键开关均随 OINK v1.7.0 发布。

[外壳契约](/zh/docs/design/shell/#keyboard-shortcuts)规定必需的绑定、钩子与存储；
[键盘导航指南](/zh/docs/customize/keyboard/)面向读者解释它们。

## 背景 {#context}

快捷键此前是随功能逐个加上的。好几个键带有两种含义或别名（`l` 与 `y` 都是切换语言，
侧栏里 `g` 与 Enter 并存，`n` 只在首页有效），热键说明分成长短不一的两栏，而编辑页面、打印、把页面交给 AI 助手这类常用操作根本没有按键。
读者还提出了主题缺少的三项能力：回到最近读过的页面、一次展开所有折叠内容、在大屏上
利用富余宽度。

## 决定 {#decisions}

### 三组单键 {#three-groups}

项目负责人于 2026-11-27 确定键位表：导航十个、页面操作九个、样式十个，每个都是只有
一种含义的裸键。热键说明以同样的三栏和顺序展示，因此它本身就是一张键盘示意图。相邻
的键承担相近的用途：`w` `a` `s` `d` 用于侧栏，`q` `e` 用于翻页，`/` `\` 用于搜索与
命令，`[` `]` 对应 ChatGPT 与 Claude，`,` `.` 调整图片大小，`-` `=` 调整宽度。

| 变化 | 理由 |
| --- | --- |
| 退役 1.6.0 键位（`h` 禅意→`z`、`l`/`y` 语言→`x`、`g` 打开侧栏项、首页 `n`） | 每个字母都要承担自己的功能；一键一义，帮助表才不会自相矛盾 |
| 命令保留在 `\`（并与 `c` 对应） | 与搜索 `/` 对称，延续旧版习惯；Gemini 不支持通过 URL 传入提示语，因此不内置 |
| 帮助键为 `'` | `'` 紧挨着 `;`，而 `;` 切换画廊布局，与切换索引布局的 `l` 相邻 |
| `m` 打开 Markdown | 双列视图、禅意模式与 Markdown 构成一排阅读视图：`b`、`z`、`m` |

`?` 与数字键保持不绑定；修饰键一律屏蔽快捷键，唯独产生 `,` `.` `;` `<` `>` `=` `+` 时放行
`Shift`，浏览器与辅助技术的快捷键因此保有各自的按键。读者也可以在热键说明底部自行关闭本站所有单键快捷键（`td-single-key-shortcuts:<basePath>`），仅保留 `Cmd/Ctrl+K` 与 `Escape`。

### 变暗，而不是隐藏 {#dim-not-hide}

页面无法执行的行留在表中，变暗显示并读作「不可用」，而不是消失。隐藏会让表格的形状
随页面变化，也无法告诉读者某项功能在别处其实存在。帮助表是每种语言一份缓存的模板；
是否可用在浏览器里每次打开对话框时判断，因为它取决于画廊是否可见、抽屉是否打开等
实时状态。

### 悬停看全表，点击弹对话框 {#hint-and-sheet}

鼠标悬停或键盘聚焦底栏 `?` 按钮时，直接在页脚上方展开完整的三栏热键说明（宽屏三栏并排，窄屏自动折行），当前页不可执行的按键同步变暗。点击 `?` 或按 `'` 则在屏幕中央弹出模态对话框，并附带默认开启的「启用快捷键」开关。

### 历史只留在浏览器里 {#local-history}

`h` 从 `localStorage` 中按时间倒序列出最近读过的页面，并排除当前页面，所以「`h` 再按
Enter」就是「回到上一页」。列表以站点基础路径为键，同一域名下的两个站点不会混在一起；
最多 100 条，只接受本站路径，可以逐条删除或整体清除。它从不外发，而且只在开启键盘
导航的页面上存在，关闭快捷键的站点什么也不会记录。

### 全部折叠，但不迷失位置 {#fold-all}

`o` 把所有可折叠内容视为一个整体：侧栏与右栏分组、`<details>`，以及被截短的代码块。
只要有任何一处处于折叠状态，就全部展开；否则全部折叠。折叠时保留当前页面所在的
分支——这正是侧栏对已保存状态采用的同一规则——而且正在阅读的那一行在上方内容高度
变化时保持不动。弹出菜单与侧栏、右栏本身的显隐不在其列：它们是临时界面或布局，
不是内容。

### 可以退回的读者宽度 {#reader-width}

`-` 与 `=` 以 100 px 为步长，在 600 px 与左右两栏之间的空间之内调整正文栏，选择对
当前浏览器中的整个站点生效。加宽到碰到两栏时保存的是「铺满」而不是像素值，换到更大的
屏幕依然铺满。某一步回到页面自身宽度时停在那里并忘掉保存的值，无需单独的重置键，
即可让每个页面恢复作者设定的 `page_width`。

### 只保留支持网址提示语的助手 {#assistants}

ChatGPT 与 Claude 接受写在网址里的提示语，Gemini 不支持这种用法，因此 OINK 不内置
Gemini 跳转。ChatGPT 与 Claude 共用需要主动开启的 `assistant_links` 开关，站点不主动
选择，就不会把网址发给第三方。

## 影响 {#consequences}

习惯了 1.6.0 键位的读者需要重新记住调整后的键位，在自己页面里写过 1.6.0 键位（`h`、`l`、`y`、`t`、`g`）的站点需要更新。键盘分块现在包含历史运行时，每个开启键盘导航的页面每次访问都会写入一条
很小的 `localStorage` 记录。没有引入新的配置、网络请求或构建步骤。

## 验证与归属 {#verification-and-ownership}

主题的 `bin/check-keyboard.py` 核对已绑定按键与文档中的键位表、分块组装和开关条件；
`tests/js` 覆盖运行时单元。文档站点的 `tests/browser/keyboard-nav.spec.mjs` 负责浏览器
验收：三栏对话框及其变暗的行、悬停热键表、历史的记录与删除、全部折叠、跨刷新保持的
读者宽度，以及页面操作键。
