读者看到的一切都来自 `content/` 下的 Markdown 文件，本栏讲怎么写它们：一篇文档页、构成侧栏的目录树，以及自带版式的各类内容，如博客文章、书籍、图片相册、发布页和 API 参考。它们共用同一套 Markdown 写法和同一组 front matter 键，所以在[编写页面](/zh/docs/write/pages/)里学到的，换到其它类型同样适用。
