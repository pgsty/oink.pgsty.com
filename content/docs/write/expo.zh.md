Expo 把一个个图片文件夹变成供读者浏览而非阅读的图集：侧栏按组列出相册，主区域显示所选相册的图片网格，点开任意一张进入查看器，可以缩放、逐张翻看。图片本身就是内容时用它，例如照片档案、截图库、一组海报或图表。只想在文章里插几张图，用 [Gallery 组件](/zh/docs/components/gallery/)更合适。本页介绍的每个控件都可以在[示例相册](/zh/expo/)里试用。

## 创建相册 {#create-an-album}

一个相册就是一个文件夹：里面的 `index.md` 描述相册，`images/` 子文件夹存放图片。图片默认以文件名作标题，所以不必为每张图建文件，只在需要更多信息的地方补元数据。

```text
content/photos/
├── _index.md
├── nature/
│   ├── _index.md
│   └── field-notes/
│       ├── index.md
│       └── images/
│           ├── 01-fern.jpg
│           └── 02-river.gif
└── buildings/
    ├── index.md
    └── images/
        └── arch.jpg
```

1. 创建分区入口，让它下面的所有页面都成为 Expo 页面：

   ```yaml {title="content/photos/_index.md"}
   ---
   title: 图片相册
   type: expo
   cascade:
     type: expo
   ---
   ```

2. 为每组相册创建主题入口：

   ```yaml {title="content/photos/nature/_index.md"}
   ---
   title: 自然
   weight: 10
   ---
   ```

3. 创建相册页面：

   ```markdown {title="content/photos/nature/field-notes/index.md"}
   ---
   title: 野外札记
   description: 一次野外观察中的植物与河流。
   weight: 10
   ---

   摄于北侧小径。
   ```

4. 将图片放入相册的 `images/` 文件夹。

分区页面列出下级主题与相册，侧栏沿用同一棵内容树，窄屏上则收进导航抽屉。相册正文可以省略，写了就显示在图片上方。

Expo 不会给图片分页，大型收藏请拆成多个相册。分区页上每张相册卡片以相册排序后的第一张图作封面；自身没有图片的主题从下级相册中借用第一张。封面填满 4:3 的画框，因此可能被裁切。

## 图片元数据 {#image-metadata}

要给图片加标题、说明、署名或指定位置，在相册 front matter 中添加 `resources` 条目。`src` 路径相对于相册文件夹。

```yaml {title="相册 front matter"}
resources:
  - src: images/01-fern.jpg
    title: 蕨叶
    params:
      id: fern
      alt: 从上方观察的一片绿色蕨叶
      caption: 北侧小径旁分叉生长的叶片。
      byline: Alex Chen
      weight: 10
```

| 字段 | 用途 |
| --- | --- |
| `title` | 图片标题；省略时由文件名生成 |
| `params.alt` | 描述图片的替代文字；省略或为空时使用标题 |
| `params.caption` | 纯文本说明 |
| `params.byline` | 纯文本署名 |
| `params.weight` | 图片排序数值；越小越靠前，默认为 `0` |
| `params.id` | 相册内稳定的图片 ID |
| `params.original` | 可选，指向同一相册页面包内另一张图片的路径 |

权重相同的图片按资源名称排序。默认权重是 `0`，所以没设权重的图片排在所有正权重图片之前；要完整地固定顺序，就给每张图都设权重。

`id` 给图片一个永久链接，本例是 `/photos/nature/field-notes/#img-fern`。只要相册 URL 不变，改了文件名这条链接依然有效。不设 `id` 时，Expo 用文件名的哈希作 ID，重命名文件就会让指向它的链接失效。ID 以 ASCII 字母或数字开头，后续字符还可以用 `_` 和 `-`，同一相册内不能重复。

若要让轻量的预览图链接到更大的原图，把原图放进 `originals/`，并设置 `params.original: originals/fern.jpg`。两者保持相同宽高比，并让 `originals/` 落在 `expo.images` 匹配范围之外，否则每张原图都会在相册里再出现一次。Expo 只读取相册页面包内的图片，从不抓取远程文件。

## 默认值 {#defaults}

在 `hugo.yml` 中设置全站的布局与图片尺寸：

```yaml {title="hugo.yml"}
params:
  ui:
    expo:
      images: images/*
      mode: wall
      size: 240
```

| 键 | 可选值 | 内置默认值 |
| --- | --- | --- |
| `images` | 相册页面包内图片资源的匹配模式 | `images/*` |
| `mode` | `wall`、`cards` 或 `seamless` | `wall` |
| `size` | `160` 至 `360` 的整数，单位为 CSS 像素 | `240` |

相册本身，或通过 `cascade` 的分区，可以在 front matter 顶层写自己的 `expo` 块：

```yaml {title="相册 front matter"}
expo:
  images: images/*
  mode: cards
  size: 280
```

页面块整体替换站点块：页面块里省略的字段取内置默认值，而不是站点块中的值。`size` 是布局努力接近的目标尺寸，不是每张图片固定的宽和高。

读者自己的选择优先于以上两者。读者选的布局和尺寸按整个站点保存在浏览器里，刷新页面、切换相册或切换外观后依然保留。浏览器存储不可用时，每个页面从你设置的默认值开始。

## 布局 {#layouts}

| 模式 | 显示方式 |
| --- | --- |
| `wall` | 展墙：按行排列图片块，间距为 6 CSS 像素 |
| `cards` | 卡片：按列排列，显示标题、说明与署名 |
| `seamless` | 无缝：按行排列图片块，块之间没有间距 |

读者用相册工具栏里的三个图标切换布局，工具栏上还有播放／暂停按钮和图片尺寸滑杆。在有鼠标的设备上，展墙与无缝模式在悬停或键盘聚焦时显示说明。相册中的图片块总是完整显示整张图片，因此宽高比极端的图片会在块内留白。

GIF 默认播放，点暂停切换为静态预览。系统要求减少动态效果时，Expo 从静态预览开始，点播放即可启动。相册里没有 GIF 时播放按钮不可用。图片在接近可见区域时才加载，但大体积的 GIF 一旦加载，仍要传输完整文件。

## 图片查看器 {#viewer}

点击图片打开查看器。小图以原尺寸显示；大图缩小到宽、高都能放进显示区域。

| 控件 | 操作 |
| --- | --- |
| 重置 | 恢复初始尺寸，并将图片居中 |
| 放大至适屏 | 缩放图片，直到受限边与显示区域对应边等长 |
| 缩小／放大 | 将当前缩放比例除以或乘以 `1.25` |
| 打开原图 | 在新标签页中打开原图文件 |
| 在相册中定位 | 关闭查看器，移动到相册中的这张图片 |
| 上一张／下一张 | 显示同一相册中的相邻图片 |
| 关闭 | 关闭查看器，将焦点返回图片链接 |

放大至适屏会让整张图片可见，并不会把浏览器切换到全屏。手动放大后图片可以超出显示区域，这时按住鼠标左键拖动，移到图片边缘即停止。在触摸屏上，放大的图片使用原生滚动；图片完整显示时，单指横向滑动切换图片；双指缩放保持浏览器原生行为。双击在初始适配尺寸与近看之间切换：缩小显示的图片以 100% 打开并保持指针下的位置，已按原尺寸显示的图片则放大至适屏。

切换图片会重置缩放比例和位置，上一张／下一张到相册首尾即停止。缩放百分比按 CSS 像素计算：100% 时，一个原图像素对应一个 CSS 像素。

## 快捷键 {#shortcuts}

在单个相册页面上（不是列出相册的分区页），开启 `keyboard_nav` 时，按 {{< kbd ";" >}} 在 `wall`、`cards`、`seamless` 三种布局之间循环，按 {{< kbd "," >}} / {{< kbd "<" >}} 将图片尺寸缩小一档（`−20 px`），按 {{< kbd "." >}} / {{< kbd ">" >}} 放大一档（`+20 px`）。

查看器有自己的一套按键。只要查看器打开，它们就生效，与 `keyboard_nav` 的设置无关，并且优先于页面的单键导航。它们不会干扰文字输入、输入法组合输入，也不接管 Ctrl／Command／Alt 组合键。

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 将放大后的图片向上／左／下／右移动 |
| Q 或 H | 上一张 |
| E 或 L | 下一张 |
| J 或 − | 缩小 |
| K、+ 或 = | 放大 |
| R 或 0 | 重置尺寸和位置 |
| F | 放大至适屏 |
| Escape | 关闭查看器 |

W、A、S、D 每按一次移动 80 CSS 像素，且只沿图片超出显示区域的方向生效。图片在横向上能完整放下时，左右方向键用于切换图片；图片宽于显示区域后，方向键改为横向滚动。在从右向左书写的语言中，方向键跟随阅读方向。

## 外观与页宽 {#appearance}

Expo 没有自己的外观设置。相册沿用站点的视觉预设（Paper、Slate、Ink 或 Terminal）及亮暗模式，读者和在其他页面上一样，从共享导航里切换；切换预设后网格会重新排布。要让读者在四种预设间选择，设置 `params.ui.preset_menu: [paper, slate, ink, terminal]`，详见[视觉预设](/zh/docs/customize/brand/#visual-presets)。顶部导航栏遵循站点的导航栏设置；相册页显示图片工具栏，不显示文章操作菜单。

相册默认占满页面的全部可用宽度，右侧没有大纲。需要较窄的正文时，在相册 front matter 中设置 `page_width`。如果站点设置了 `params.ui.shell_types`，务必保留 `expo`，否则相册会失去侧栏。

## 翻译与其他输出 {#translations-and-outputs}

要做中文相册，在 `index.md` 旁添加 `index.zh.md`，并为每个翻译的分区添加 `_index.zh.md`。两种语言共用图片文件；在各自页面中翻译标题、描述与资源元数据，同一张图片保持相同的 `id`，两种语言的链接才能对应。

没有 JavaScript 时相册照样可用：图片链接直接打开原图，说明保持可见。在开启了相应输出的站点上，Print 显示静态预览，Markdown 与 LLMSFULL 列出图片链接及元数据，RSS 包含静态的图片说明。开启这些输出的方法见[打印支持](/zh/docs/customize/print/)与[智能体输出](/zh/docs/customize/agents/)。

## 检查相册 {#check-an-album}

1. 运行 `hugo --printPathWarnings`，阅读告警。
2. 打开每个相册，确认图片顺序、标题与说明。
3. 分别打开一张小图、一张宽图、一张长图，相册里有 GIF 的话也打开一张。
4. 试用重置、放大至适屏、缩放、拖动、快捷键和在相册中定位。
5. 检查两种语言、窄屏、站点提供的每种预设，以及亮暗模式。

相册为空，通常是 `type` 不对、文件夹不是页面包（缺少 `index.md`），或者 `expo.images` 什么也没匹配到。默认值看似没有生效，通常是被浏览器里保存的读者选择覆盖了，或者页面的 `expo` 块整体替换了站点块。
