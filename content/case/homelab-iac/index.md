[blue126.github.io/IaC](https://blue126.github.io/IaC/) documents a Proxmox
cluster infrastructure-as-code lab covering Terraform, Ansible, deployment,
architecture, and incident runbooks. Maintained alongside the IaC code in
[`blue126/IaC`](https://github.com/blue126/IaC), it highlights OINK's
single-source HTML, Markdown, and `llms.txt` outputs on the `paper` preset.

## What it demonstrates {#what-it-demonstrates}

- Co-locating operational runbooks and architecture notes inside an active
  Terraform and Ansible repository.
- Enabling OINK's AI-agent outputs (`index.md` and `llms.txt`) alongside a clean
  human-readable documentation portal.
- Using OINK's Paper preset for high-signal infrastructure runbooks without custom
  CSS bloat.
