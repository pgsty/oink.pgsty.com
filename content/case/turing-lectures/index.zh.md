[c2j.github.io/ACM-Turing-Award-Lectures](https://c2j.github.io/ACM-Turing-Award-Lectures/) 收录了 1966–2024 年全部 42 篇 ACM 图灵奖获奖演讲中文译文，以及四卷《图灵全集》百余篇经典文献译作。仓库 [`c2j/ACM-Turing-Award-Lectures`](https://github.com/c2j/ACM-Turing-Award-Lectures) 在 GitHub Actions 中直接由原始译稿生成 OINK 站点，启用了构建期 KaTeX 编号公式（`{#eq-N}`）、译注侧栏与 `hypothes.is` 社会性批注。

## 它展示了什么 {#what-it-demonstrates}

- 利用 OINK 的 KaTeX 构建期直通渲染与编号公式锚点排版高密度计算机科学经典论文。
- 在 GitHub Actions 中仅靠 Hugo 与 Go 完成大型历史文献站构建，无需任何 Node.js 工具链。
- 在保持源 Markdown 于 GitHub 直接可读的前提下，轻量接入 `hypothes.is` 读者协作批注。
