[istarwyh.github.io/cc4pm/docs](https://istarwyh.github.io/cc4pm/docs/) publishes the course documentation and interactive syllabus for **CC4PM** (*Claude Code for Product Managers*), maintained in [`istarwyh/cc4pm`](https://github.com/istarwyh/cc4pm). Built with OINK into over 150 generated HTML pages covering 89 lessons, installation guides, templates, and reference deliverables, the curriculum even dedicates Lesson 24.9 to building content sites with OINK itself.

## What it demonstrates {#what-it-demonstrates}

- Generating a multi-track course documentation tree from repository courseware Markdown while preserving source edit links and original downloadable files.
- Running full Chinese local search and strict internal-link verification across more than 17,000 rendered links on GitHub Pages.
- Integrating OINK smoothly under a `/docs/` section beside an independent custom course homepage.
