[ansible-vms.pages.dev](https://ansible-vms.pages.dev/) is the bilingual documentation site for **ansible-vms**, a declarative KVM and libvirt virtual machine provisioning toolkit maintained in [`mars-base/ansible-vms`](https://github.com/mars-base/ansible-vms). Built on OINK's `paper` preset as a companion site to `pgcli.pages.dev`, it delivers 28 pages covering CSV-driven VM inventories, cloud images, bridges, snapshots, and firewall automation.

## What it demonstrates {#what-it-demonstrates}

- Reusing a consistent OINK Paper layout and Cloudflare Pages workflow across sibling infrastructure repositories.
- Co-locating focused bilingual operations documentation inside an Ansible automation repository with `llms.txt` enabled.
