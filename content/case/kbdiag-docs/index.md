[Kevin-wenyu.github.io/kbdiag-docs](https://Kevin-wenyu.github.io/kbdiag-docs/) is the bilingual documentation site for **kbdiag**, a single-binary read-only command-line diagnostics tool for KingbaseES database instances. Built directly from OINK Starter in [`Kevin-wenyu/kbdiag-docs`](https://github.com/Kevin-wenyu/kbdiag-docs), the 62-page site pairs a concise centered hero with English and Chinese operational manuals.

## What it demonstrates {#what-it-demonstrates}

- Starting cleanly from `pgsty/oink-starter` to ship a dedicated bilingual documentation repository for a database CLI tool.
- Structuring diagnostic workflows, check capabilities, and evidence reports with local search and `llms.txt`.
