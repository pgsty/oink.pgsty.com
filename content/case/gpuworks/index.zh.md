[gpuworks.readthedocs.io](https://gpuworks.readthedocs.io/release-26.12/) 是面向 GPU 算力的轻量级管理平台 **GPUWorks** 的中英双语文档站。文档源稿位于 [`flitai-io/gpuworks`](https://github.com/flitai-io/gpuworks)，主题与构建资源托管在配套仓库 [`flitai-io/gpuworks_website`](https://github.com/flitai-io/gpuworks_website)，并通过 Read the Docs 托管 `stable`、`latest` 与发行分支多版本手册。

## 它展示了什么 {#what-it-demonstrates}

- 在 GitHub Pages 与 Cloudflare Pages 之外，将 OINK 文档站直接接入 Read the Docs 的多版本发布体系。
- 将业务仓库中的双语 Markdown 源稿（`docs/`、`docs-en/`）与配套仓库中的主题资产解耦维护。
- 在同一文档外壳中统一呈现用户教程、操作指南、参考手册、架构说明与架构决策记录（ADR）。
