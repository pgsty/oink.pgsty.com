[gpuworks.readthedocs.io](https://gpuworks.readthedocs.io/release-26.12/) is the bilingual Chinese and English documentation site for **GPUWorks**, a lightweight GPU compute management platform for serving AI models. Maintained across [`flitai-io/gpuworks`](https://github.com/flitai-io/gpuworks) and its companion theme host [`flitai-io/gpuworks_website`](https://github.com/flitai-io/gpuworks_website), the site pairs OINK's documentation shell with Read the Docs multi-version hosting (`stable`, `latest`, and release branches).

## What it demonstrates {#what-it-demonstrates}

- Deploying an OINK documentation site directly on Read the Docs with versioned release branches alongside GitHub Pages or Cloudflare Pages workflows.
- Separating product Markdown sources (`docs/`, `docs-en/`) in the application repository from shared theme and build assets in a companion website repository.
- Delivering user guides, operator manuals, architecture decision records, and API references in both Chinese and English.
