[ayusne.github.io/zhangmuchuan](https://ayusne.github.io/zhangmuchuan/)（**张暮川**）是维护在 [`AyuSne/zhangmuchuan`](https://github.com/AyuSne/zhangmuchuan) 的个人技术随笔与译文博客。站点包含 77 个 Markdown 文件，覆盖原创长文、中文译文与专题系列，在 OINK `paper` 风格基座上定制了「**纸·墨·朱**」全站视觉外壳——配以朱印「川」标识、宋体大标题与竖排印记，同时完整保留四套视觉预设、深浅色切换、本地搜索与图片缩放。

## 它展示了什么 {#what-it-demonstrates}

- 仅通过 CSS token 与局部模板覆盖打造鲜明的东方编辑视觉风格，不改动文章源码，也不破坏上游 OINK 升级链路。
- 用正式架构决策记录（`ADR-0001` 与 `ADR-0002`）及四预设矩阵回归测试管理站点定制边界。
- 在同一阅读壳中清晰区分原创长文、译文专栏与文章系列。
