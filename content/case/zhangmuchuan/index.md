[ayusne.github.io/zhangmuchuan](https://ayusne.github.io/zhangmuchuan/) (*张暮川*) is a personal technical essay and translation blog maintained in [`AyuSne/zhangmuchuan`](https://github.com/AyuSne/zhangmuchuan). Built on OINK's `paper` preset across 77 Markdown files covering essays, Chinese translations, and thematic series, it layers a bespoke **Paper · Ink · Vermilion** (*纸·墨·朱*) visual identity—complete with a vermilion seal mark, serif display headings, and vertical colophon accents—while preserving all four OINK visual presets, dark mode, local search, and image zoom.

## What it demonstrates {#what-it-demonstrates}

- Deeply customizing OINK's visual identity through CSS tokens and focused layout overrides without modifying article Markdown or breaking upstream theme upgrades.
- Documenting theme selection and visual customization in repository architecture decision records (`ADR-0001` and `ADR-0002`) backed by automated regression checks across all four presets.
- Combining original essays, curated translations, and multi-article series inside one quiet reading shell.
