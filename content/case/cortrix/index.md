[cortrix.ai/docs](https://cortrix.ai/docs/) is the official documentation portal for **Cortrix**, an open-source semantic storage and memory layer for AI agents. Maintained in the `docs-site/` directory of [`cortrix/cortrix`](https://github.com/cortrix/cortrix), the 45-page English site runs on OINK's `slate` preset with a custom brand accent, literal identifier search, Mermaid diagram zoom, and `{.wide .expand}` full-window reference tables.

## What it demonstrates {#what-it-demonstrates}

- Publishing an AI infrastructure project's documentation, architecture guides, and OpenAPI reference from a dedicated `docs-site/` module inside the main code repository.
- Using OINK's `{.wide .expand}` tables and `search_keywords` to keep dense configuration parameters, error codes, and MCP tool tables readable and discoverable.
- Deploying cleanly under a product subpath (`/docs/`) while publishing `llms.txt` alongside HTML documentation.
