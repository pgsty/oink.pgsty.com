[le-shi.github.io](https://le-shi.github.io/) (*Le Shi 系统手册*) is a personal
systems operations handbook maintained in
[`le-shi/le-shi.github.io`](https://github.com/le-shi/le-shi.github.io). It
captures verified installation, environment, and recovery recipes across Linux
Mint and Windows 11 using a crisp editorial hero and clean documentation trees.

## What it demonstrates {#what-it-demonstrates}

- Turning everyday workstation setup and recovery notes into a tidy, searchable
  reference manual.
- Keeping a small single-language documentation site focused and easy to read on
  desktop and mobile.
