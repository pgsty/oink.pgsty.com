[piglet.run](https://piglet.run/) is the product site and bilingual manual for
**Piglet**, an agentic PostgreSQL runtime that turns one Linux host into an
AI-ready workspace. With 74 Markdown files across English and Chinese, it pairs
a high-impact asymmetric landing hero (dark terminal preview, mascot badge, and
key metrics) with focused installation and configuration documentation.

## What it demonstrates {#what-it-demonstrates}

- Launching a modern AI/infrastructure product with a bold custom accent and
  visual terminal preview inside OINK's landing shell.
- Keeping a fast-moving product's marketing surface and bilingual docs inside
  one lightweight Hugo repository.
