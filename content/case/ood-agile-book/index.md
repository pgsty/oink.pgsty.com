[polla.dev/ood-agile-book](https://polla.dev/ood-agile-book/) publishes *Object Oriented Development and Agile Practices: Designing, Testing and Evolving Software with AI Assistance* by Polla Fattah. Maintained in [`polla-fattah/ood-agile-book`](https://github.com/polla-fattah/ood-agile-book) across 65 Markdown files, it combines a full book manuscript, code companion, course blueprint and syllabus, and lecture slides inside OINK's Book shell.

## What it demonstrates {#what-it-demonstrates}

- Publishing an entire postgraduate course—book manuscript, companion code solutions, syllabus, and slides—from one OINK repository.
- Using PlantUML diagrams, Giscus comments, and `llms.txt` inside a cohesive academic Book layout.
