[istarwyh.github.io/yourbuddy](https://istarwyh.github.io/yourbuddy/) is the product website and manual for **YourBuddy**, a customizable macOS AI workbench built on DeepSeek Harness and maintained in [`istarwyh/yourbuddy`](https://github.com/istarwyh/yourbuddy). It uses OINK's centered landing hero, clean feature sections, and integrated navigation covering workbench guides, default plugins, extensions, releases, and direct Apple Silicon downloads.

## What it demonstrates {#what-it-demonstrates}

- Combining a desktop software landing page, plugin documentation, and release download links in one OINK repository.
- Keeping typography-led product positioning crisp and fast-loading on GitHub Pages under a repository subpath.
