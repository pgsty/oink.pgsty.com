[codingpracticegroup.github.io/pmpp5-zh](https://codingpracticegroup.github.io/pmpp5-zh/) 是 GPU 与 CUDA 经典教材《大规模并行处理器编程（第 5 版）》的中英对照阅读站，源码见 [`CodingPracticeGroup/pmpp5-zh`](https://github.com/CodingPracticeGroup/pmpp5-zh/pull/1)。项目通过 Python 管线将中文 LaTeX 译稿、41 张 TikZ 矢量插图与英文文本按 230 个共享标题锚点对齐，覆盖全部 24 章与 3 个附录，按 `B` 键即可在 OINK **双列视图** 中左右同步核读。

## 它展示了什么 {#what-it-demonstrates}

- 实战运用 OINK 原生双列视图（`params.ui.compare: true`）与共享标题锚点，实现技术译作的中英并排同步滚动核读。
- 将自动化 LaTeX → Markdown 与 TikZ 插图管线接入 OINK 书籍外壳和 KaTeX 构建期公式渲染。
