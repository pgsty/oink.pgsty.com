[cassa.au](https://cassa.au/) is the official website of the **Computing and
Security Student Association (CASSA)** at Edith Cowan University in Australia.
Maintained in
[`cassa/static-CASSA-website`](https://github.com/cassa/static-CASSA-website),
the site uses OINK's centered text hero alongside pages for About, Blog,
Membership, Timeline, and club merchandise.

## What it demonstrates {#what-it-demonstrates}

- Using OINK outside software documentation for a real academic club and student
  organization website.
- Pairing a crisp `align: center` landing hero with membership onboarding, event
  timelines, and club news.
- Keeping a volunteer-maintained site lightweight enough for student committees
  to update in plain Markdown and YAML.
