[pgcli.pages.dev](https://pgcli.pages.dev/) is the bilingual English and Chinese documentation site for **pgcli**, an open-source PostgreSQL instance and storage-stack manager maintained in [`mars-base/pgcli`](https://github.com/mars-base/pgcli). Spanning 218 Markdown pages on OINK's `paper` preset, it documents CLI workflows, Patroni high availability, Ansible playbooks, and support guides, deployed to Cloudflare Pages.

## What it demonstrates {#what-it-demonstrates}

- Hosting a 218-page bilingual infrastructure manual inside the same repository as the CLI tool and publishing directly to Cloudflare Pages.
- Using OINK's centered Paper hero to introduce an operational CLI clearly before routing readers straight into documentation and quickstart guides.
- Keeping documentation and `llms.txt` in sync with active software releases.
