[hugegraph.apache.org](https://hugegraph.apache.org/) is the official website and
documentation portal for **Apache HugeGraph**, a top-level Apache Software
Foundation full-stack graph platform covering graph databases, graph computing,
toolchains, and Graph AI. Its source repository
[`apache/hugegraph-doc`](https://github.com/apache/hugegraph-doc) manages nearly
300 Markdown files across English and Chinese trees on OINK's `slate` preset.

## What it demonstrates {#what-it-demonstrates}

- Customizing OINK's brand tokens and hero styling to deliver a distinct
  full-bleed project identity without forking the theme shell.
- Serving a large open-source community with versioned documentation, downloads,
  a blog, and community guides in both English and Chinese.
- Contributing upstream reading repairs back into OINK while migrating an
  established Apache project site.
