[mooncake.pgsty.com](https://mooncake.pgsty.com/) documents **Mooncake**
(`pg_mooncake`, Moonlink, and DuckDB execution for PostgreSQL), bringing
real-time columnstore mirrors and Apache Iceberg v2 tables to PostgreSQL. Across
144 bilingual Markdown pages, it shares the same architectural diagram aesthetic
and documentation shell as sibling PGSTY extension sites.

## What it demonstrates {#what-it-demonstrates}

- Maintaining a consistent visual family across multiple database product sites
  without duplicating layouts or CSS frameworks.
- Explaining complex HTAP and lakehouse data flows cleanly through diagram-led
  hero art and structured docs.
