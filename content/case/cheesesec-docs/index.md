[docs.cheesesec.com](https://docs.cheesesec.com/) is the official product manual and engineering documentation hub for **CheeseSec** security solutions, covering CheeseWAF and CheeseSec Plugins. Maintained in [`LaokeQwQ/CheeseSec_Docs`](https://github.com/LaokeQwQ/CheeseSec_Docs) across 96 Markdown files in English and Chinese, it enters straight into OINK's three-column reading shell with product cards, sidebar navigation, and `llms.txt`.

## What it demonstrates {#what-it-demonstrates}

- Skipping a marketing hero so security engineers land immediately in structured architecture, deployment, and policy configuration manuals.
- Hosting multiple sibling security products (`CheeseWAF` and `Plugins`) inside one bilingual OINK documentation tree.
