[docs.cheesesec.com](https://docs.cheesesec.com/) 是安全方案 **CheeseSec** 的官方产品手册与工程文档中心，涵盖 CheeseWAF 与 CheeseSec Plugins。仓库 [`LaokeQwQ/CheeseSec_Docs`](https://github.com/LaokeQwQ/CheeseSec_Docs) 维护了 96 个中英双语 Markdown 页面，跳过营销首页直接进入 OINK 三栏文档外壳，并配备产品入口卡片与 `llms.txt`。

## 它展示了什么 {#what-it-demonstrates}

- 跳过营销落地页，让安全工程师打开首页即直达架构说明、部署指南与策略配置手册。
- 在同一棵双语 OINK 文档树中统一组织多个关联安全产品（`CheeseWAF` 与 `Plugins`）。
