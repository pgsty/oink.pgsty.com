[whlle-yi.github.io](https://whlle-yi.github.io/) is a bilingual Chinese-and-English computer science portfolio and blog maintained in [`whlle-yi/whlle-yi.github.io`](https://github.com/whlle-yi/whlle-yi.github.io). Starting from OINK Starter and vendoring the theme locally for network-free builds, it combines a pixel-art display banner, wireframe geometric graphics, and an interactive command-line terminal widget directly above OINK's blog and project pages.

## What it demonstrates {#what-it-demonstrates}

- Blending playful custom interactive landing components (pixel typography and a live browser terminal) seamlessly into OINK's bilingual navbar, search, and dark-mode shell.
- Vendoring OINK locally inside a personal portfolio repository for zero-network builds with KaTeX math and `llms.txt`.
