[caps.pgsty.com](https://caps.pgsty.com/) is the full bilingual product site for
the native macOS **Capslock** utility (tap for Escape, hold for Hyper). Whereas
sibling case [caps.vonng.com](/case/capslock/) shows a minimal two-page
Karabiner configurator, `caps.pgsty.com` scales the product up to 88 Markdown
files with a centered hero, visual keyboard layout diagram, release blog, and
native app downloads.

## What it demonstrates {#what-it-demonstrates}

- Evolving a small tool site into a full bilingual desktop product portal with
  docs, blog, and downloads while keeping one OINK shell.
- Pairing a clean `align: center` landing hero with custom interactive visual
  diagrams right below the fold.
