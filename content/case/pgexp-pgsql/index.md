[pgexp.pgsql.cc](https://pgexp.pgsql.cc/) publishes *Postgres by Example* as a
bilingual Chinese and English tutorial book covering 57 concise, hands-on SQL
lessons (120 Markdown files). Every lesson pairs syntax-highlighted SQL examples
with downloadable script bundles under OINK's Book reading shell.

## What it demonstrates {#what-it-demonstrates}

- Publishing a code-heavy, lesson-by-lesson technical tutorial using OINK's Book
  shell and Chroma SQL syntax highlighting.
- Pairing bilingual lesson pages with downloadable runnable SQL archives and
  whole-book print output.
