[mapseekai.github.io/tasklane-web](https://mapseekai.github.io/tasklane-web/) is the official Chinese product website and documentation hub for **tasklane**, a TypeScript background task and worker-pool runtime for browsers and Node.js. Maintained in [`mapseekai/tasklane-web`](https://github.com/mapseekai/tasklane-web), the 49-page site runs on OINK's `slate` preset with a custom Cobalt accent and opens with an asymmetric two-column hero illustrating the main-thread-to-worker dispatch flow.

## What it demonstrates {#what-it-demonstrates}

- Organizing 49 product documentation pages using the Diátaxis structure (quickstarts, concepts, guides, API reference, and architecture) alongside a release changelog blog.
- Pairing a custom interactive flow diagram card directly inside the OINK landing hero.
- Publishing a clean subpath documentation site on GitHub Pages with local Chinese search and `llms.txt`.
