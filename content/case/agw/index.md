[agw-ai.dev](https://agw-ai.dev/) is the product site and documentation portal
for **AGW**, a self-hosted workspace and gateway for coordinating coding agents
such as Claude Code, Codex, and Pi. Living inside the `site/` directory of
[`zxyao145/agw`](https://github.com/zxyao145/agw), it pairs a clean centered
landing page with 88 bilingual English and Chinese documentation pages and
release downloads.

## What it demonstrates {#what-it-demonstrates}

- Hosting an OINK documentation site inside a `site/` subdirectory of an active
  application monorepo.
- Pairing a typography-led `align: center` hero with quick-start docs and
  downloads for an AI developer tool.
- Maintaining synchronized English and Chinese guides alongside application code.
