[ggrelease.github.io](https://ggrelease.github.io/) is the Chinese documentation site for **grelease**, a full-stack canary release and blue-green deployment framework built around Spring Cloud Gateway and etcd. Maintained in [`ggRelease/ggRelease.github.io`](https://github.com/ggRelease/ggRelease.github.io), it uses OINK's centered landing hero to route readers cleanly into separate user and maintainer guides.

## What it demonstrates {#what-it-demonstrates}

- Using a compact OINK site to publish clear audience-split entry points (user guide vs. maintainer guide) for an open-source release framework.
- Deploying straight to an organization's root GitHub Pages domain with local Chinese search and `llms.txt`.
