[ggrelease.github.io](https://ggrelease.github.io/) 是基于 Spring Cloud Gateway 与 etcd 的前后端一站式灰度发布框架 **grelease** 的中文官方文档站。站点维护在 [`ggRelease/ggRelease.github.io`](https://github.com/ggRelease/ggRelease.github.io)，采用 OINK 居中首屏清晰分流使用指南与维护者指南两个核心入口。

## 它展示了什么 {#what-it-demonstrates}

- 用精简的 OINK 站点为开源发布框架提供清晰的角色分流入口（使用指南与维护者指南）。
- 直接发布到 GitHub 组织根域名，自带本地中文检索与 `llms.txt`。
