[leafz.net](https://leafz.net/) (*一叶方舟*) is a minimalist personal engineering and writing site maintained in [`imleafz/leafz.net`](https://github.com/imleafz/leafz.net). Built on OINK's `paper` preset with Giscus comments and `llms.txt`, its author also maintains an independent community OINK skill in [`imleafz/agent-skills`](https://github.com/imleafz/agent-skills) for Claude Code and Codex workflows.

## What it demonstrates {#what-it-demonstrates}

- Using a stripped-back centered Paper hero for a focused personal writing site with almost zero visual distraction.
- Pairing OINK's native Markdown authoring model with AI coding-agent skills in daily publishing.
