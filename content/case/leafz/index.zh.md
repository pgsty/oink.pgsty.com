[leafz.net](https://leafz.net/)（**一叶方舟**）是维护在 [`imleafz/leafz.net`](https://github.com/imleafz/leafz.net) 的极简个人工程与随笔博客。站点基于 OINK `paper` 风格，集成 Giscus 评论与 `llms.txt`；其作者还在 [`imleafz/agent-skills`](https://github.com/imleafz/agent-skills) 中开源维护了一套面向 Claude Code 与 Codex 的社区 OINK Agent Skill。

## 它展示了什么 {#what-it-demonstrates}

- 以高度克制的居中 Paper 首屏承载纯粹的个人写作与技术沉淀。
- 将 OINK 原生 Markdown 模型与社区 AI Agent 技能结合用于日常建站与维护。
