[ryanyhy.github.io/YHY-Website](https://ryanyhy.github.io/YHY-Website/) is an 86-page bilingual personal study hub focused on robotics, vision-language navigation, and AI agents, maintained in [`RyanYhy/YHY-Website`](https://github.com/RyanYhy/YHY-Website). It pairs a highly customized dark pixel-terminal hero with OINK's blog and project shells, shares GitHub Discussions comments across both GitHub Pages and Vercel deployments, and publishes hands-on tutorials on setting up OINK, Giscus, and an Obsidian-to-OINK publishing workflow.

## What it demonstrates {#what-it-demonstrates}

- Replacing the landing hero with a bespoke dark pixel-art terminal identity while keeping OINK's full docs, blog, KaTeX, PlantUML, and search shell intact.
- Sharing one Giscus discussion thread across bilingual pages and dual static hosts (GitHub Pages and Vercel).
- Documenting a repeatable Obsidian-to-OINK personal publishing workflow for non-frontend writers.
