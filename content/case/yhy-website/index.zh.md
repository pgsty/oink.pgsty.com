[ryanyhy.github.io/YHY-Website](https://ryanyhy.github.io/YHY-Website/) 是聚焦机器人、视觉语言导航与 AI Agent 的 86 页中英双语学习站，源码位于 [`RyanYhy/YHY-Website`](https://github.com/RyanYhy/YHY-Website)。站点在 OINK 外壳之上定制了极具辨识度的深色像素终端首屏，实现了 GitHub Pages 与 Vercel 双站点跨语种共享 Giscus 评论，并开源了 OINK 建站笔记与 Obsidian → OINK 写作规范。

## 它展示了什么 {#what-it-demonstrates}

- 用深色像素终端风深度定制首页，同时完整保留 OINK 的博客、项目栏、KaTeX、PlantUML 与全文搜索。
- 在中英文双语与 GitHub Pages / Vercel 双部署之间共享同一套 Giscus 评论讨论区。
- 面向非前端作者沉淀出可复用的 Obsidian 笔记到 OINK 静态博客发布工作流。
