[ariana-yang.github.io/system-design-notes-zh](https://ariana-yang.github.io/system-design-notes-zh/) 将 28 章系统设计中文学习笔记整理为在线书籍，从基础扩展一直讲到股票交易所设计。仓库 [`Ariana-Yang/system-design-notes-zh`](https://github.com/Ariana-Yang/system-design-notes-zh) 通过 Hugo 挂载将章节组织进 OINK 书籍阅读外壳并启用本地检索。

## 它展示了什么 {#what-it-demonstrates}

- 将按章编号的 Markdown 学习笔记仓库直接发布为流畅的在线阅读书籍。
- 在 GitHub Pages 上零后端提供中文全文检索与连续章节翻页体验。
