[ariana-yang.github.io/system-design-notes-zh](https://ariana-yang.github.io/system-design-notes-zh/)
publishes a structured 28-chapter Chinese study guide to system design, from
foundations to stock exchanges. Built in
[`Ariana-Yang/system-design-notes-zh`](https://github.com/Ariana-Yang/system-design-notes-zh),
it mounts Markdown chapters into OINK's Book reading shell with local search.

## What it demonstrates {#what-it-demonstrates}

- Turning a repository of numbered Markdown study notes into a clean online
  reading experience with OINK's Book shell.
- Providing zero-backend Chinese search and sequential chapter reading on GitHub
  Pages.
