OINK signs formal release notes and project announcements. This profile keeps
project authorship distinct from the individual maintainers who write design
notes, tutorials, and engineering reports.

## About OINK {#about}

OINK is a local-first Hugo theme for technical documentation. It provides the
shared shell, navigation, publishing surfaces, and Markdown-native components
used across the Pigsty documentation family.
