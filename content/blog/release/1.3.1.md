> [!NOTE] Current release: OINK 1.3.2
> The [1.3.2 release notes](/blog/release/1.3.2/) supersede this version's
> compiler setup: use Hugo Extended 0.168.0 with built-in LibSass and visible
> warnings. Do not install Dart Sass or enable warning-fatal builds for OINK.
> The requirements below record 1.3.1 as released.

OINK 1.3.1 fixes four reading problems while preserving compact layouts by
default. It advances the build baseline to **Hugo Extended 0.168.0** and
**standalone Dart Sass 1.105.2**, tested with **Go 1.27.2**. CI automatically
follows the latest stable Go and Hugo releases and records the versions used.
The module continues to declare Go **1.27.0** as its minimum.

## Reading repairs {#repairs}

- **Markmap:** node text follows the article color across light/dark modes,
  visual presets, and restored preferences. Print keeps dark text on white.
  Resolves [#47](https://github.com/pgsty/oink/issues/47).
- **TOC:** the fixed right rail clears the footer, including pages without a
  sidebar. It recalculates when tabs, blog view changes, or loaded media move
  the footer without scrolling. Flow outlines and mobile drawers keep their
  layout. Resolves [#49](https://github.com/pgsty/oink/issues/49).
- **Technical tables:** `.td-table--wide` preserves readable identifiers inside
  a horizontal scroll region and bounds long descriptions. Ordinary tables,
  `.fields`, and static outputs keep their layout.
  Resolves [#53](https://github.com/pgsty/oink/issues/53).
- **FileTree:** `wrap=true` displays complete long comments within their column;
  the default remains compact. Resolves [#51](https://github.com/pgsty/oink/issues/51).

The compact-sidebar leaf issue [#45](https://github.com/pgsty/oink/issues/45)
was already fixed in 1.3.0; that fix remains included.

## Choose FileTree wrapping {#filetree-wrap}

````markdown
```filetree {wrap=true}
- storage/
  - metadata/ # Schema definitions: property keys, vertex and edge labels, indexes, and counters.
  - graph/    # Graph data: vertices, edges, index tables, and OLAP analysis data.
```
````

Omitting `wrap`, or setting `wrap=false`, keeps compact desktop and tablet rows.
With `wrap=true`, comments wrap and rows grow; filenames still use ellipsis.
Directory folding, divider resizing, mobile stacking, and expanded Print keep
their existing behavior. See the [FileTree guide](/docs/components/filetree/#wrap).

## Build requirements {#build-requirements}

Install **Hugo Extended 0.168.0 or newer** and **standalone Dart Sass 1.105.2**, with its
`sass` executable on `PATH`. Ordinary site builds still need no Node.js or npm.
Hugo 0.168 deprecates LibSass, so main and ReDoc styles now use Dart Sass.

Project-variable hooks and the separate Font Awesome stylesheet remain supported.
Only four known Bootstrap/import-scope language deprecations are suppressed;
other warnings still fail `--panicOnWarning` publishing gates.

## Upgrade {#upgrade}

After installing the compiler:

```sh
hugo mod get github.com/pgsty/oink@v1.3.1
env -u HUGO_MODULE_REPLACEMENTS GOWORK=off HUGO_MODULE_WORKSPACE=off hugo --minify --environment production --printPathWarnings --panicOnWarning
```

Vendored and classic-theme consumers must refresh their actual theme files too.
Keep `preset: paper` and `preset_menu: [paper, slate, ink, terminal]`. Review
nearby diagrams, footer clearance, technical tables, and trees with wrapping enabled.
