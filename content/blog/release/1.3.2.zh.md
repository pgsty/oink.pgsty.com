OINK 1.3.2 撤回了 1.3.1 引入的强制 Dart Sass 安装要求。普通站点构建与预览使用
**Hugo Extended 及其内置 LibSass**。主样式、ReDoc 样式、深色语法高亮和项目
SCSS 钩子继续可用。1.3.1 中独立的可读性修复与 FileTree 修复全部保留。

{{< release-card >}}

## 保留的阅读体验修复 {#reading-repairs}

本版本保留 1.3.1 引入的社区修复：

- **Markmap**：节点文字在明暗模式与不同视觉预设下保持可读。
- **TOC**：固定目录避让页脚，正文尺寸变化后仍会重新计算。
- **技术表格**：使用 `.td-table--wide` 显式开启，在横向滚动区域内保留标识符宽度。
- **FileTree**：使用 `wrap=true` 显式开启完整长注释，默认仍为紧凑行。

这些修复由 [@imbajin](https://github.com/imbajin) 贡献，同时附有主题夹具、测试与
配套双语文档。[1.3.1 贡献记录](/zh/blog/release/1.3.1/#thanks)逐项链接到对应 pull request。

## 构建要求 {#build-requirements}

> [!NOTE] 公开标签与当前基线
> OINK v1.3.2 发布时以 Hugo Extended 0.166.0 为最低版本和默认版本，并接受
> Hugo 0.168.0 的 LibSass 弃用告警。维护中的站点现在使用下文固定的 0.168.0
> 基线；本次文档更新不改变已公开的标签。

所有维护中的站点在开发、CI、预览与部署中统一使用 **Hugo Extended 0.168.0**。
模块声明的 Go 最低版本为 **1.27.0**，开发使用 **Go 1.27.2**。Go 负责解析
Hugo Modules；普通站点构建不需要额外的 Sass 程序、Node.js 或 npm。

禁止启用 `--panicOnWarning` 或 `HUGO_PANICONWARNING`。告警保持可见并接受审阅；
Hugo 报告的上游 LibSass 弃用告警允许出现。检查器直接验证主题诊断与安全回退。

默认 Hugo 版本保持固定。后续升级必须保持普通用户的依赖边界。如果 Hugo 新版本
移除内置 LibSass，需要另行评估兼容方案。

## 升级 {#upgrade}

更新模块版本：

```sh
env -u HUGO_MODULE_REPLACEMENTS GOWORK=off HUGO_MODULE_WORKSPACE=off \
  hugo mod get github.com/pgsty/oink@v1.3.2
env -u HUGO_MODULE_REPLACEMENTS GOWORK=off HUGO_MODULE_WORKSPACE=off \
  hugo --environment production --minify --printPathWarnings
```

提交更新后的 `go.mod` 和 `go.sum`。移除仅为 OINK 1.3.1 添加的 Sass 安装步骤，
将默认 Hugo workflow 版本设为 `0.168.0`。使用 vendor 主题的站点还需刷新对应副本。

现有内容、外观设置和项目 SCSS 定制不需要迁移。维护中的站点保留 Paper 默认风格与
显式的 `preset_menu: [paper, slate, ink, terminal]` 读者菜单。详情参见
[工具链契约](/zh/docs/design/architecture/#hugo-toolchain)。

## 验证 {#validation}

主题的编译检查在 `PATH` 中没有 Sass 程序的环境下，构建真实的主样式和 ReDoc
样式，并验证项目变量、项目样式钩子与深色 Chroma 调色板。Hugo 0.168.0 构建保留
可见告警；编译检查器接受已知的上游 LibSass 弃用告警，拒绝非预期诊断。
