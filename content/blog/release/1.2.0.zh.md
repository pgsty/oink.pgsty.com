> [!IMPORTANT] 发布说明草案
> 2026 年 10 月 4 日按 `v1.1.0` 之后的变更更新，覆盖主题 HEAD `b0af631` 及
> 后续工作树修改。1.2.0 尚未发布，本站仍固定 `v1.1.0`，本地检查使用同级主题
> checkout。页面日期保留最初的草案日期。

OINK 1.2.0 改善从创作到阅读、出版的整条路径：导航与元数据使用一致的页面范围，
浏览器增强保留内容与焦点，维护工具保护站点源码。既有 1.1.0 站点无需批量迁移
内容，也没有新增的必填配置。

## 主要变化 {#at-a-glance}

- 导航树、上一页/下一页与导航 JSON 使用一致的范围。
- 博客每一分页拥有自身的 canonical URL，SEO 备用链接只表示真实译文。
- CJK 关键词命中显示可读摘要，大纲跟踪正确处理字面百分号。
- Landing 在没有 JavaScript 时仍可阅读，复制与快捷键保留读者焦点。
- 特色图片、图表端点与构建时数学渲染遵循各自契约。
- 仓库操作兼容 Windows 路径与外部挂载，避免暴露构建机器路径。
- 快照与 PDF 工具保护输入，约束出版时的资源访问。
- 新增维护工具，清点消费站点并验证精确主题升级。

## 导航、元数据与图片 {#navigation-and-metadata}

`data/docs_nav.json` 显式提供空 `sections` 数组时会告警，并回退到内容树。显式树
与内容树都剪掉 `toc_hide` 子树。导航 JSON 将 `manual_link_relref` 解析到与侧栏
相同的站内目标；手动占位项不进入翻页序列。

博客索引的每一分页使用自身的 canonical URL，纯表格索引不再产生多余分页器。
`hreflang` 与 Open Graph 语言备用链接只列真实译文。缺译时，可见语言选择器仍可
回退到目标语言首页，但 SEO 备用链接不包含这个回退。从第 2 页起，归档页不再
输出语言备用链接，因为各语言归档的分页边界可能不同。

有源文件的页面按显式 `images`、页面包图片、继承图片的顺序选择特色图。页面自己
写出的值即使与 cascade 值相同，仍视为显式值；没有源文件的生成页将解析后的
图片视为显式值。非字符串资源 `alt` 元数据会警告并被忽略，保留作者编写的图片
替代文字。

## 渲染与阅读交互 {#rendering-and-interactions}

Landing 内容在增强前可见，只有成功挂接 observer 后才启用隐藏与揭示效果。
禁用 JavaScript 或脚本请求失败不会留下空白页面。指标动画结束时保留作者编写的
显示字符串，包括缩写值、前缀与后缀。

剪贴板回退恢复输入框或文档选区及其方向，移除临时控件后归还焦点；复制过程中
其他控件已获得焦点时不再抢回。焦点移到命令面板外后，Tab 导航仍能恢复。
Ctrl/Cmd+K 与页面快捷键会让位于其他已打开的弹窗，包括可见的固定定位 ARIA
dialog。

只命中 `search_keywords` 的 CJK 查询显示页面描述或摘要，不再显示同义词串；
正文命中仍保留周围文字作为上下文。大纲链接解码合法 URL 片段，非法百分号
序列则使用字面的标题 ID，页尾标题也遵循同一规则。

PlantUML 与 Draw.io 在加载运行时前校验端点。有效值是带主机名的 HTTP(S) URL
或站内路径；非法类型、协议、协议相对 URL、原始反斜线、空白与无路径引用会
告警并停用集成。禁用 PlantUML 端点时保留源码。Draw.io 编辑与图片缩放采用
独立控件，编辑按钮支持键盘、触屏与强制配色模式。

数学公式仍由 Hugo 生成 HTML 与 MathML，使用本地 CSS。Hugo 0.160.1 生成的
KaTeX 类名会适配随主题分发的样式，不改变 TeX 或 MathML。编号公式图注在窄屏
换行。图片检查核对实际文件与尺寸，输出 golden 忽略不同受测 Hugo 版本间
无实质意义的 KaTeX 测量精度差异。

## 仓库操作 {#repository-actions}

编辑、历史与新建子页链接先将物理源码路径统一为 `/`，再检查站点边界。外部挂载
需要显式 `path_base_for_github_subdir` 映射。映射后路径为空、仍是绝对路径、
带盘符或向父目录逃逸时，不生成这些源码操作。文档与项目 issue 链接各自遵循
原有仓库配置。Windows 映射使用 `/` 分隔符，详见
[仓库链接](/zh/docs/customize/repository/#imported-content)。

## 文档与兼容性 {#compatibility}

双语指南已按当前 1.2.0 工作实现校准：导航与译文 SEO、源码路径、搜索摘要、
图片优先级、图表端点、数学公式、渐进增强与出版保护。CSP 说明涵盖内联脚本、
样式和 style 属性；界面语言包接受字符串与受支持的复数消息映射。这些说明
修正没有新增前端依赖。

Hugo Extended 兼容下限仍为 **0.160.1**，CI 使用 **0.165.0**，模块声明 Go
**1.27.0**。在 Hugo 0.160.x 上，非默认通用 `zh` 与区域中文语言包并存时，
仍需 `locale: zh-CN`。

采用 1.2.0 前，将复制到站点内的导航、博客、图片、数学和运行时覆盖与新版主题
比较。先修正非法端点与资源元数据，再执行将警告视为失败的构建；PDF 输出还需
审查远程资源需求。标签正式发布且可解析后，按
[1.2 升级清单](/zh/docs/admin/upgrade/#preparing-1-2)验收。

[OINK CLI 草案](/zh/docs/cli/)介绍独立、可选的 `oink-cli` 项目。它仍是未发布的
`0.1.0-dev` 候选，使用自己的版本号；主题与普通 Hugo 构建不依赖它。

## 维护与出版工具 {#maintenance-and-publication}

快照工具在清理前拒绝与站点、选定主题、运行工具的 checkout 或其他快照重叠的
目标，包括符号链接别名、`--keep` 保留输出与 RTL 快照名。选择另一个主题不会
撤销对运行工具 checkout 的保护。

`bin/book-pdf.py` 约束间接网络访问与导航。未开启 `--allow-remote-resources` 时，
由 CSS、SVG 发起的媒体请求仅限本地出版 origin 与 data URL。CSP sandbox 禁用
脚本，即使允许远程资源也拒绝 meta-refresh 导航。资源符号链接不能逃出构建树。
远程资源开关只允许被动 HTTP(S) 媒体，不开放脚本或本地文件访问；替换输出仍需
`--force`。

迁移工具保留列表与引用块中嵌套的围栏示例，包括示例内字面的引用和围栏标记。
展开受支持的旧式代码块时仍保留外层列表结构。

## 消费站升级流程 {#consumer-upgrades}

新增 Python 工具 `bin/update-consumers.py`，清点指定根目录下的直属项目或显式
选择的站点。默认只读清点；`--write` 更新模块文件，`--check` 校验精确模块图，
并在禁用 Go/Hugo workspace 与环境模块替换后执行严格构建。

自动发现跳过链接 worktree、隐藏副本与非默认分支。维护者需要核对跳过或阻塞项、
持久化替换与 vendor 内容。`--refresh-vendor` 必须显式选择，仅更新 `go.mod`
不会刷新 `_vendor/`。单个发现失败不影响其余站点；模块更新失败恢复原模块文件，
构建失败则保留新 pin 便于排查。工具不会提交、推送或部署，详见
[消费站维护契约](/zh/docs/design/migration/#updating-consumers)。

## 验证与发布状态 {#verification}

最终工作树应通过主题归属检查器、运行时测试，以及文档站的 `make check` 和
`make browser`。出版使用严格生产构建，报告实际 Hugo 版本与无障碍扫描范围。
之前带日期的验收结果保留为历史证据，不替后续修改背书。

发布精确标签、解析公开模块归档、更新消费站 pin 与验证托管产物，仍是彼此独立的
发布步骤。
