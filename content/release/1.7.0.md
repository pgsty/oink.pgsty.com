OINK 1.7.0 brings six new content components (Timeline, Update, Video, Audio,
Social, and Map with vendored Leaflet `1.9.4`), typeset rich-text copy
that pastes cleanly into external editors, a unified system of 29 single-key
shortcuts with local browsing history, fold-all, reading-width steps, and a reader
opt-out, plus a typography and palette pass across all four visual presets.
The plain CSS builds on any supported Hugo edition. This release was validated
with Hugo `0.170.1` and Go `1.27.4` for Hugo Modules. See the
[toolchain contract](/docs/design/architecture/#hugo-toolchain).

## Six new content components {#components}

Each new component keeps a Markdown-native or minimal authoring form and defines
deterministic output across HTML, Print, Markdown/LLMS, and RSS. The theme now
ships 30 shortcodes, 123 plain CSS layers in `main`, 26 vendored dependencies in
`VENDOR.json`, and 264 keys in each of the 32 locale catalogs.

- **[Timeline](/docs/components/timeline/).** A Markdown definition list
  followed by `{.timeline}` renders a vertical axis with a marker column. CSS
  only, with no runtime script.
- **[Update](/docs/components/update/).** A heading marked
  `{.update date="2026-11-27" tags="Added, Changed"}` stays an ordinary heading
  for the TOC, anchors, search, and Print, followed by a `<time>` and tag-chip
  metadata strip whose tokens stay separated when copied.
- **[Video](/docs/components/video/).** Block image syntax targeting a video
  file (`![alt](demo.mp4)`) renders a native player supporting `caption`, `num`,
  `poster`, `track`, `width`, `height`, and `autoplay=true` (muted, looped,
  playing only while visible and never under reduced motion). YouTube, Bilibili,
  and Vimeo URLs render link cards by default; platforms listed in
  `params.video_embeds` swap in their player on click from validated IDs.
- **[Audio](/docs/components/audio/).** Block image syntax targeting an audio
  file renders a titled native player with `caption`, `id`, and automatic
  metadata preloading for the first six players. Local audio and video show elapsed playback in the page accent.
  Their shared media script keeps one audible player active at a time.
- **[Social](/docs/components/social/).** The `social` shortcode quotes
  posts from X (default), Bluesky, Mastodon, Threads, Weibo, Zhihu, Telegram,
  LinkedIn, or `none` (default for nested quotes) entirely from the page,
  composing Markdown, images, galleries, and nested quotes without platform
  scripts. The quote makes no platform request; a reader's browser loads any
  remote avatar or attachment the author supplies.
- **[Map](/docs/components/map/).** A `map` code fence produces a numbered place list with
  OpenStreetMap links in HTML, Print and RSS. Markdown and LLMS keep the fence. Configuring `params.map` with `enable: true`, an
  HTTPS tile template (`{z}`, `{x}`, `{y}`/`{-y}`, optional `{s}`, `{r}`) and
  required `attribution` adds an interactive map through vendored Leaflet
  `1.9.4` (BSD-2-Clause), supporting `dark_tiles`, `attribution_url`,
  `subdomains`, `max_zoom` (`1–22`), and `loading: click` host consent.

## Typeset copy {#typeset-copy}

Selecting and copying article prose now leaves the page as clean, self-contained
rich text drawn from the active preset's print palette in pixel sizes, without
the page canvas color, heading anchor hashes, copy buttons, line numbers, or
shell chrome. Editors such as WeChat's rich-text editor no longer receive grey
boxes or dark-mode backgrounds.

- Selecting the whole page copies only the article body; a phrase inside one
  line travels as bare inline markup; source line breaks between two CJK
  characters no longer paste as spaces; ordered lists preserve partial `start`,
  `reversed`, and `value` numbers; and code blocks keep syntax token colors,
  with a dark code card staying dark.
- `text/plain` is unchanged. Set `params.ui.rich_copy: false` (or page front
  matter `rich_copy: false`) to restore browser-default HTML copying.

## Twenty-nine shortcuts, browsing history, and reading width {#keyboard}

Single-key navigation is organized into three groups (**Navigation**,
**Actions**, and **View**: 10, 9, and 10 shortcuts). Hovering the bottom-bar `?`
button previews the full three-column cheat sheet directly above the footer, and
clicking `?` or pressing `'` opens it as a centered top-layer dialog—even in Zen
Mode or on `footer_style: none` pages. Actions unavailable on the current page
stay visible in the grid, dimmed and labeled for screen readers.

- **Reader toggle (`Enable shortcuts`).** Readers can toggle global single-key
  shortcuts on or off (enabled by default) from **Enable shortcuts** in the
  shortcut dialog or the focus stop right after **Skip to content**. The choice
  persists per site path across languages (`Ctrl/Cmd+K` remains active).
- **Local browsing history (`H`).** `H` or the Command Palette's **Browsing
  history** command (`browse_history`) opens a list of up to 100 pages
  visited on the site, filtered by title and path as you type, and stored
  strictly in browser `localStorage` scoped by base path.
- **Fold or unfold all (`O`).** Expands or collapses sidebar and right-rail
  groups, `<details>` callouts and file trees, and collapsible code blocks in
  one keystroke while keeping the reader's active path open and scroll position
  steady.
- **Reading-width steps (`-` / `=`).** Narrows or widens the article column in
  `100 px` steps between `600 px` and the container width, persisting in
  `localStorage` and restoring before paint; stepping back onto the page's own
  width resets the override.
- **Shortcut changes from 1.6.0.** Zen Mode moves from `H` to `Z` (`H` is browsing
  history), language cycling moves to `X`, preset cycling is `T`, color mode is
  `Y`, blog index layout is `L`, version cycling is `V`, language home is `G`,
  command-only palette stays on `\` (with `C`), and `[` and `]` trigger
  ChatGPT and Claude. `G` no longer opens the focused tree item (`Enter` and
  `Space` remain), and the home page `N` section alias is gone (`J` remains).
  Non-text inputs such as gallery radios and range sliders no longer block
  shortcuts after a click.
- **Focus and input methods.** Closing the palette or history no longer raises
  the footer `?` hover sheet when focus returns to it, and an Escape that
  dismisses IME candidates (including Safari's trailing 229 keydown) stays with
  the input method.

## Refined presets and CJK typography {#presets}

All four visual presets received a typography and palette pass, with distinct
CJK system font stacks and zero bundled CJK font files:

- **Paper** moves from grey `#f7f6f3` to an ivory canvas (`#faf9f5`), ink
  `#1f1e1c`, and a warm clay UI accent (`#9b4a28`, dark `#de8460`) while keeping
  blue underlined links in running text and setting Song headings over Plex Sans
  and Hiragino Sans GB / system Hei prose. Sites that prefer the previous blue
  accent can set `params.ui.theme_color: '#2b5f8c'`.
- **Ink** sets Inter and Hei headings (weight `700`, `1 px` `h2` rule) over
  system-serif and Song prose at `17 px`, restricting link underlines to running
  text, so cards, Book contents, and file trees no longer take them.
- **Slate** retains Inter and Hei with rounded table header corners;
  **Terminal** now sets screen prose in IBM Plex Mono as well (keeping IBM Plex
  Sans in print), sets `##`/`###` heading marks light and slightly apart, and
  colors emphasis.
- A table on its own in a tab fills the panel to both edges. Wide tables scroll inside the panel on a phone.
- **OINK Kai and prose typography.** Emphasis, citations, and blockquotes use
  local system Kai through the CJK-only `OINK Kai` face so Han characters are
  never slanted while Latin keeps real italics. CJK headings sit at zero
  tracking; prose enables `text-autospace: normal` and `text-wrap: pretty`,
  tables use tabular numerals, bare `<kbd>` tags render as keycaps, and an
  explicit `params.ui.fonts.ui` or `fonts.body` reaches the headings in every
  preset unless `fonts.heading` names its own face.

## Markmap controls, ECharts themes, and publishing fixes {#fixes}

- **Markmap corner icons and SVG download.** Replaces the boxed "Fit to window"
  button below Markmap diagrams with subtle, borderless bottom-right icon
  buttons for **Fit to window** and **Download SVG** (exporting a standalone
  SVG with resolved theme colors and canvas background).
- **Site ECharts themes.** Define named themes on `window.OinkEchartsThemes` so
  lazy-loaded ECharts fences register and apply them automatically before
  drawing, guarded inside the chart error boundary.
- **Styled archived-version banner.** `params.archived_version` now renders a
  tinted `role="note"` banner with an archive icon across all four presets, dark
  mode, forced colors, RTL, and print, warning once and omitting empty output if
  `params.version` is missing.
- **Vendored library refresh.** Updated Mermaid to `12.4.0`, Swagger UI to
  `5.36.0`, ReDoc to `3.2.0`, Asciinema Player to `3.19.0`, `@plantuml/core` to
  `1.2026.10`, and `@markmap/*` to `1.1.1` alongside newly vendored Leaflet
  `1.9.4` in `VENDOR.json`.
- **Asciinema, Draw.io, accessibility, and card fixes.** Asciinema `markers`
  now reach `asciinema-player` `3.19` as `[time, label]` pairs and skip empty
  items after a comma; sidebar switcher, pager, and blog gallery links match
  their visible text in accessible names; Draw.io auto-detection skips video
  posters, social avatars, and map thumbnails; and `.td-blog-card__image` sets
  `height: auto` so raster thumbnails keep their 16:9 frame.

## Upgrading to 1.7.0 {#upgrade}

OINK 1.7.0 introduces no breaking template or stylesheet changes for sites
already on `v1.6.0`. Review [Upgrade to 1.7.0](/docs/admin/upgrade/#preparing-1-7)
for Paper's clay accent opt-back, updated keyboard bindings, `rich_copy`
opt-out, and CSP directives for `params.map` and `params.video_embeds`.

Pin the published release once `v1.7.0` is live:

```sh
hugo mod get github.com/pgsty/oink@v1.7.0
hugo mod tidy
hugo --environment production --minify --printPathWarnings
```

Commit the updated `go.mod` and `go.sum`, keep warnings visible, and never
enable `--panicOnWarning` or `HUGO_PANICONWARNING`.
