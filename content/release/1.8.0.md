OINK 1.8.0 expands the visual system to **six styles** with dedicated dark
modes—restoring Paper's classic reading palette, introducing **GitHub** and
**News**, reimagining **Ink** as a brush-written manuscript, and turning Dark
**Terminal** into a restrained phosphor screen—while replacing mismatched
browser audio and video strips with one themed control bar and standardizing
offline quoted social posts on the Markdown-native `> [!SOCIAL]` callout form.
The plain CSS builds on any Hugo edition (tested on Hugo `0.170+`) with no
minimum version floor and no Sass compiler. See the
[toolchain contract](/docs/design/architecture/#hugo-toolchain).

## Six visual styles and dedicated dark modes {#presets}

The Style menu now ships six distinct reading personalities—**Paper**, **Slate**,
**GitHub**, **Ink**, **News**, and **Terminal**—all bundled inside the single
plain-CSS stylesheet with no external font requests and dedicated Giscus comment
stylesheets. Each dark mode keeps the light mode's typography while choosing its
own nocturnal palette rather than mechanically inverting colors.

- **Paper (`preset: paper`, default).** Returns to its classic warm-paper look:
  canvas `#f7f6f3`, ink `#21201c`, IBM Plex Sans for both prose and headings
  paired with platform Hei for Chinese, blue links (`#2b5f8c`, dark `#7db5e6`)
  serving as the UI accent, semibold prose links, regular-weight framed tables,
  and a hairline quotation rule. Shared typography upgrades remain: upright
  `OINK Kai` for Chinese emphasis, bare `<kbd>` keycaps, quieter list markers,
  tabular figures, and zero tracking on CJK headings.
- **Slate (`preset: slate`).** Preserves OINK's cool blue-gray technical look
  with Inter, Chakra Petch display headings, IBM Plex Mono code, and platform
  Hei.
- **GitHub (`preset: github`, experimental).** Reproduces Markdown as GitHub
  renders a README in both light (`#ffffff` / `#1f2328`) and dark (`#0d1117` /
  `#f0f6fc`): GitHub's system UI and monospace stacks, `16 px` / `1.5` prose,
  semibold headings with `h1`/`h2` hairlines and chain-link anchors, grey code
  blocks (titled blocks framed as file boxes), fully ruled zebra tables sized to
  their content, GFM alert colors on callouts, `0.25em` rules, the NavList bar
  on the active sidebar row, and green primary buttons. Values derive from
  `github-markdown-css` `5.9.0` and `@primer/primitives` `11.10.0` (MIT), with
  three contrast adjustments (`#268838` dark primary hover, `#bc4c00` light
  selected-tab underline, link blue dark focus ring) and upright `OINK Kai` for
  Chinese emphasis.
- **Ink (`preset: ink`, experimental) — the written page.** Warm aged paper
  (`#f3ead7` shading to `#e8dabd` at window edges) with ink `#241a10` and
  vermilion `#a8321b`. Latin uses Palatino everywhere (upright titles, italic
  sections, text-weight headings with faint ink bleed); Chinese uses
  system Kai (`OINK Kai`, now with a dedicated bold face for installed bold Kai)
  in headings and chrome and Fangsong (`OINK Fangsong`, falling back to Song) in
  prose. Sections open under a tapered brush stroke, quotations hang from a
  fading vermilion stroke, Chinese `strong` renders as vermilion emphasis dots,
  Blog posts and Book chapters open with a vermilion initial, and the active
  navigation row carries a vermilion dot. **Dark Ink** sets silver type
  (`#e3ddd0`) with gold headings and accent (`#dcb766`) on indigo-violet paper
  (`#1b1730` → `#120f22`).
- **News (`preset: news`, experimental) — the printed page.** Press black
  (`#161616`) on grey newsprint (`#f0eee8`) with one spot blue (`#1f4f7a`),
  flat geometry with zero border radius and zero shadow. Book serif prose with
  Song for Chinese, heavy Times New Roman over Songti Black (bold Hei on
  Windows) for headlines, and Didot/Bodoni masthead wordmarks where installed;
  navigation, menus, search, and lists share the text serif so the page reads as
  one printed sheet. Double rules under the site masthead and page title, a
  deck and uppercase dateline under the title, thick-and-thin section rules,
  pull quotes between rules, and open tables between ink hairlines. **Dark
  News** is a darkroom: silver type (`#d8d6d1`) on `#0f0f0f` with safelight
  orange (`#f2804a`) links and a subtle corner glow.
- **Terminal (`preset: terminal`, experimental).** Light Terminal stays
  unchanged. **Dark Terminal** becomes a restrained phosphor screen: pale
  grey-green body text (`#c9d2cc`) on `#050806`, phosphor green (`#3dff7a`)
  reserved for glowing headings, links, accent, and the current navigation and
  search cursor bar, amber (`#e5b45a`) for heading marks, emphasis, and quote
  rules, faint scan lines, and a multi-hue syntax palette (green keywords,
  amber strings, cyan numbers, pale names, dim comments).

`params.ui.theme_color` continues to override the accent in every preset, and
`bin/check-presets.py` now checks WCAG AA text contrast at shaded canvas edges
(`--td-preset-canvas-edge`) as well as on flat canvases.

## Appearance menu and interactive style tiles {#appearance}

- **Fixed six-style grid.** The Appearance menu lists presets in one canonical
  order—**Paper, Slate, GitHub** over **Ink, News, Terminal**—and `T` cycles
  them in the same order. Menus with three, five, or six presets lay out in
  three columns (`24 rem` wide) directly above the three Color cards (**Light**,
  **Dark**, **System**); two or four presets keep two columns. On narrow phones
  (`320 px` bottom sheet), buttons stack icon over label so every name fits.
- **Accurate color-mode trigger.** Whenever the menu offers Color, the toolbar
  trigger shows the reader's active choice—sun for Light, moon for Dark, and a
  half-filled circle for System—applied via `data-td-color-mode` before first
  paint so the icon never flashes. A style-only menu shows a palette icon.
- **Shortcut hints and renamed group label.** When keyboard navigation is on
  and the device supports hover, the two legends display **Style (T)** and
  **Color (Y)** (hiding the hints when a reader turns single-key shortcuts off).
  The color group is renamed to **Color** across all 32 locales.
- **Interactive landing style tiles.** A `capabilities` component-board item on
  a Landing page can now carry `preset: <name>`; when that preset is offered in
  the site's `preset_menu`, the tile renders as an interactive button
  (`data-td-preset-select` with `aria-pressed`) so readers can preview styles
  directly on the home page.

## Unified single-bar audio and video controls {#media}

Local [Audio](/docs/components/audio/) and [Video](/docs/components/video/)
players now share one theme-rendered control row (`.td-media__controls`),
eliminating browser-inconsistent native controls and duplicate progress bars
across Chromium, Firefox, and Safari.

- **One three-color progress bar.** Each player draws a single seek track
  stacking played time (the page accent color), buffered ranges (a deeper
  neutral), and unloaded time (a light neutral), keeping at least `3:1` contrast
  between played time and both neutrals across all six presets and light/dark
  modes. Each preset shapes the bar to match its visual grammar: a pill in Paper
  and Slate, an `8 px` bar in GitHub, square-cut rules in Ink and News, and a
  block cursor over an accent-tinted buffer in Terminal.
- **Complete playback controls.** Play/pause, elapsed time, seek slider,
  duration, a playback-speed button cycling `1×`, `1.25×`, `1.5×`, `2×`, and
  `0.75×`, and a mute toggle whose volume bar unfolds on hover or focus (omitted
  on coarse touch pointers where device buttons control volume). Video adds a
  captions toggle (when a `track` is configured), a full-screen button keeping
  the control row beneath the picture, and click-on-picture play/pause.
- **Keyboard, responsive, RTL, print, and no-JS support.** Arrow keys seek
  `5 s`, Page keys seek `10 %`, and Home/End jump to either end; single-key page
  shortcuts yield while focus is inside the player controls. Narrow rows give
  the seek bar its own line, the control row stays left-to-right on RTL pages,
  forced colors map to system colors (`Highlight`, `GrayText`, `Canvas`), print
  hides the row, and disabling JavaScript leaves the browser's native controls
  usable.

## Native `[!SOCIAL]` quoted-post callouts {#social}

Quoted social posts use the Markdown-native `> [!SOCIAL]` callout form: the
title line carries the author name and handle (as an inline code span), and an
attribute line directly beneath supplies `avatar`, `date`, `url`, and
`platform`.

````markdown {title="Source"}
> [!SOCIAL] Ron `@RonVonng`
>
> One PostgreSQL documentation theme, six visual styles, zero Node toolchain.
>
> ![The OINK home page](/images/hero-light.webp)
{avatar="images/ron-vonng.webp" date="2026-11-28" url="https://x.com/RonVonng/status/1871040275575124082" platform="x"}
````

- **Readable everywhere as plain Markdown.** On GitHub, in Markdown editors,
  and in Obsidian, the source reads as an ordinary blockquote; Markdown and
  LLMS outputs preserve the authored callout and attribute line verbatim.
- **Full page Markdown in the body.** Inline formatting, footnotes, attached
  images with Image Zoom, `gallery` fences, local videos, and nested
  `> [!SOCIAL]` quoted posts compose directly inside the body. The card adds no
  JavaScript and makes no requests to a social platform. Image Zoom, galleries,
  and media load their usual page runtimes. Nested cards use the compact
  `.td-social .td-social` style.
- **Neutral platform icons.** `platform` defaults to `none` (omitting the icon
  and platform label) and accepts `x`, `bluesky`, `mastodon`, `threads`,
  `weibo`, `zhihu`, `telegram`, `linkedin`, or `none`. See the
  [Social guide](/docs/components/social/).

## Toolchain, locales, and fixes {#fixes}

- **Dark Paper framed table headers.** The header band now uses the `#262420`
  tertiary ground, so it stands out against the `#1f1e1a` frame.
- **No artificial Hugo floor.** Removed the `min_version` / `module.hugoVersion.min`
  floor from `theme.toml` and `hugo.yaml`; OINK uses plain CSS and is tested on
  Hugo `0.170+` with no Sass compiler or Extended edition required.
- **Inventory and 32-locale parity.** OINK 1.8.0 ships **29** shortcodes,
  **123** plain CSS layers in `main`, **26** vendored dependencies in
  `VENDOR.json`, and **274** keys in each of the **32** locale catalogs (adding
  `ui_preset_github`, `ui_preset_news`, and eight `ui_media_*` player labels,
  and updating `ui_appearance_mode` to "Color").
- **Consumer tooling.** `bin/update-consumers.py --check-appearance` now checks
  for Paper as default and all six styles in `preset_menu`.

## Upgrading to 1.8.0 {#upgrade}

Review [Upgrade to 1.8.0](/docs/admin/upgrade/#preparing-1-8-0) before updating
your pin:

- **Six-style menu.** To offer all six styles, set
  `params.ui.preset_menu: [paper, slate, github, ink, news, terminal]`. Paper
  returns to its classic `#f7f6f3` canvas and link-blue accent; sites that want
  a serif editorial page can opt into `preset: news`, and sites using
  `preset: ink` should review its warm manuscript palette and Palatino/Kai/Fangsong
  typography.
- **Social callouts (breaking).** The `social` shortcode of 1.7.0 is removed,
  and a page that still calls it fails to build. Quoted posts use
  `> [!SOCIAL]`; convert old calls with
  `python3 bin/migrations/oink06.py migrate --site <dir> --only social --write`
  (dry run first without `--write`), then run
  `python3 bin/migrations/oink06.py check --site <dir>` to list anything left.
- **Custom media CSS.** If site CSS targeted `.td-media__progress`, remove or
  adapt it for `.td-media__controls`.

Pin the published release once `v1.8.0` is tagged:

```sh
hugo mod get github.com/pgsty/oink@v1.8.0
hugo mod tidy
hugo --environment production --minify --printPathWarnings
```

Commit the updated `go.mod` and `go.sum`, keep warnings visible, and never
enable `--panicOnWarning` or `HUGO_PANICONWARNING`.
