OINK 1.7.0 新增六种内容组件（时间线、更新条目、视频、音频、帖子与内置 Leaflet `1.9.4` 的地图），加入面向外部富文本编辑器的排版复制，将键盘快捷键重构为 29 个快捷键的三栏单键体系并新增本地浏览历史、一键折叠、正文宽度调节与读者开关，同时对四套视觉预设的配色与中文排版完成整体打磨。纯 CSS 可用受支持的任意 Hugo edition 构建。本次发布使用 Hugo `0.170.1` 和 Go `1.27.4` 验证了 Hugo Modules 构建，最低版本见[工具链契约](/zh/docs/design/architecture/#hugo-toolchain)。

## 六种新内容组件 {#components}

每个新组件都采用原生 Markdown 或极简写法，并在 HTML、打印、Markdown/LLMS 与 RSS 中给出确定输出。主题现包含 30 个短代码、`main` 样式表共 123 层纯 CSS、`VENDOR.json` 收录 26 项依赖，32 份界面语言包各含 264 个键。

- **[时间线](/zh/docs/components/timeline/)**：Markdown 定义列表后附 `{.timeline}` 即可渲染带标记列的纵向时间轴。纯 CSS 实现，无需脚本。
- **[更新条目](/zh/docs/components/update/)**：标题附 `{.update date="2026-11-27" tags="新增, 变更"}` 后仍保留原有标题语义（目录、锚点、搜索与打印不变），下方紧跟 `<time>` 与标签元信息条，复制时字段间自动保留分隔。
- **[视频](/zh/docs/components/video/)**：块级图片指向视频文件（`![说明](demo.mp4)`）即渲染原生播放器，支持 `caption`、`num`、`poster`、`track`、`width`、`height` 与 `autoplay=true`（静音循环、仅在可见时播放、遵循减弱动态偏好）。YouTube、Bilibili 与 Vimeo 链接默认渲染外链卡片；在 `params.video_embeds` 中显式启用的平台会在点击后按校验过的 ID 就地加载播放器。
- **[音频](/zh/docs/components/audio/)**：块级图片指向音频文件即渲染带标题的原生播放器，支持 `caption`、`id` 与前六个播放器自动预加载元数据。本地音视频用页面强调色显示已播进度。共享的媒体脚本让同页同时只有一个有声播放器在播。
- **[帖子](/zh/docs/components/social/)**：`social` 短代码完全在页面内引用帖子，支持 X（默认）、Bluesky、Mastodon、Threads、微博、知乎、Telegram、LinkedIn 与 `none`（嵌套引用的默认值），正文可自由组合 Markdown、图片、画廊与嵌套引用，无需平台脚本，也不向平台发请求；作者提供的远程头像或附件由读者的浏览器加载。
- **[地图](/zh/docs/components/map/)**：`map` 围栏在 HTML、打印和 RSS 中输出带 OpenStreetMap 链接的编号地点列表。Markdown 与 LLMS 保留围栏。配置完整的 `params.map`（`enable: true`，HTTPS 瓦片模板含 `{z}`、`{x}`、`{y}`/`{-y}` 及可选 `{s}`、`{r}`，以及必需的 `attribution`）后，通过内置的 Leaflet `1.9.4`（BSD-2-Clause）在 HTML 中叠加交互地图，支持 `dark_tiles`、`attribution_url`、`subdomains`、`max_zoom`（`1–22`）与 `loading: click` 点击同意后加载。

## 排版复制 {#typeset-copy}

在正文区域选区并复制时，剪贴板会得到基于当前预设打印调色板、以像素字号内联排版的干净富文本，剔除页面底色、标题锚点 `#`、复制按钮、行号与外壳控件，避免粘贴到微信公众号等富文本编辑器时出现灰底框或深色背景。

- 全选页面时只复制正文主体；单行内的短语保持行内标记；两个中日韩字符之间的源码换行不再变成多余空格；有序列表局部选区保留真实的 `start`、`reversed` 与 `value` 序号；代码块保留语法高亮配色与深色卡片外观。
- `text/plain` 纯文本输出保持不变。如需恢复浏览器默认富文本复制，设置 `params.ui.rich_copy: false`（或页面 front matter `rich_copy: false`）。

## 二十九个快捷键、浏览历史与阅读宽度 {#keyboard}

单键快捷键重构为三组共 29 个快捷键（**导航** 10 项、**操作** 9 项、**样式** 10 项）。鼠标悬停底栏 `?` 按钮即可在底栏上方直接预览完整的三栏快捷键面板，点击 `?` 或按 `'` 则在浏览器顶层弹出居中模态对话框——即使在禅意模式或 `footer_style: none` 页面也随时可用。当前页不可执行的操作仍保留在格子里，置灰并向读屏器标明不可用。

- **读者开关（启用快捷键）**：读者可在快捷键弹窗底部的 **启用快捷键** 复选框（默认开启），或「跳转到主要内容」之后的焦点停留处随时关闭或重新启用全局单键快捷键；偏好按站点路径跨语言保存在本地（`Ctrl/Cmd+K` 始终保留）。
- **本地浏览历史（`H`）**：按 `H` 或在命令面板执行 **浏览历史**（`browse_history`）可按标题与路径过滤最近访问的最多 100 条站内页面，数据仅存于按基础路径隔离的浏览器 `localStorage`。
- **一键展开 / 折叠全部（`O`）**：一次按键即可展开或收起侧栏与右栏分组、`<details>` 折叠提示块与文件树以及可折叠代码块，同时保持当前页所在分支展开且阅读位置不跳动。
- **阅读宽度调节（`-` / `=`）**：以 `100 px` 为步长在 `600 px` 至容器宽度间收窄或加宽正文栏，持久化到 `localStorage` 并在首帧绘制前恢复；步进回到页面默认宽度时自动清除覆盖。
- **相对 1.6.0 的键位调整**：禅意模式从 `H` 改到 `Z`（`H` 改为浏览历史），切换语言改为 `X`，切换视觉预设为 `T`，切换明暗模式为 `Y`，切换博客索引视图为 `L`，切换版本为 `V`，回到当前语言首页为 `G`，纯命令模式仍保留在 `\`（并与 `C` 对应），`[`、`]` 分别打开 ChatGPT 与 Claude。`G` 不再打开侧栏中聚焦的条目（`Enter` 与 `Space` 照旧可用），首页的 `N` 分节别名已移除（`J` 保留）。点击画廊单选框或滑块等非文本控件后不再屏蔽快捷键。
- **焦点与输入法**：关闭命令面板或浏览历史、焦点回到页脚 `?` 按钮时，不再弹出悬停速查表；用 Escape 关闭输入法候选（包括 Safari 随后补发的 229 keydown）时，这次 Escape 留给输入法处理。

## 四套视觉预设与中文排版 {#presets}

四套预设统一完成配色与排版打磨，各配备独立的系统中文字体栈，且不向站点打包任何中文字体文件：

- **Paper** 将纸面底色从冷灰 `#f7f6f3` 调为暖白 `#faf9f5`、墨色 `#1f1e1c` 与陶红强调色（`#9b4a28`，暗色 `#de8460`），正文行内链接保持蓝色细下划线，以宋体标题配 Plex Sans 与冬青黑体 / 系统黑体正文。若希望沿用之前的蓝色强调色，设置 `params.ui.theme_color: '#2b5f8c'`。
- **Ink** 采用 `700` 字重 Inter 与黑体标题（`h2` 上方 `1 px` 细线）配 `17 px` 衬线 / 宋体正文，链接下划线仅用于正文段落，不再出现在卡片、书籍目录或文件树中。
- **Slate** 延续 Inter 与黑体，并为表格表头加入顶部圆角；**Terminal** 屏幕正文同步改为 IBM Plex Mono（打印仍用 IBM Plex Sans），弱化并拉开 `##`/`###` 标题井号，强调文字改用配色区分。
- 单独占用标签页的表格贴齐面板两侧，宽表在手机上可在面板内横向滚动。
- **OINK Kai 与中文排版细节**：斜体强调、引文与引用块通过仅覆写中日韩字符集的 `local()` 字体 `OINK Kai` 调用系统楷体，避免汉字被机械倾斜，同时保留西文真正斜体。中日韩标题零字距；正文启用 `text-autospace: normal` 与 `text-wrap: pretty`；表格启用等宽数字；原生 `<kbd>` 标签直接呈按键样式；显式设置的 `params.ui.fonts.ui` 或 `fonts.body` 会作用于所有预设的标题，除非 `fonts.heading` 另行指定。

## 思维导图控件、ECharts 主题与发布修复 {#fixes}

- **Markmap 右下角图标与 SVG 下载**：将思维导图下方带边框的「适应窗口」文字按钮替换为右下角无边框微弱图标按钮，提供 **适应窗口** 与 **下载 SVG**（导出解析好主题配色与画布底色的独立 SVG 文件）。
- **站点自定义 ECharts 主题**：在 `window.OinkEchartsThemes` 上注册主题对象后，懒加载的 ECharts 图表会在绘制前自动注册并应用对应主题，且受图表异常兜底保护。
- **归档版本横幅样式**：`params.archived_version` 现渲染带归档图标与 `role="note"` 的浅底提示条，覆盖全部四套预设、深浅色、强制颜色、RTL 与打印；缺少 `params.version` 时仅告警一次且不输出空元素。
- **内置 JS 运行时更新**：`VENDOR.json` 同步刷新 Mermaid `12.4.0`、Swagger UI `5.36.0`、ReDoc `3.2.0`、Asciinema Player `3.19.0`、`@plantuml/core` `1.2026.10` 与 `@markmap/*` `1.1.1`，并新增内置 Leaflet `1.9.4`。
- **Asciinema、Draw.io、无障碍与卡片修复**：Asciinema `markers` 现以 `[time, label]` 二元组传给 `asciinema-player` `3.19` 并忽略逗号后的空白尾项；侧栏切换器、上下页与博客画廊链接的无障碍名称包含可见文本；Draw.io 自动探测跳过视频封面、社交头像与地图缩略图；`.td-blog-card__image` 补齐 `height: auto`，位图缩略图保持 16:9 画幅、不再被拉伸。

## 升级到 1.7.0 {#upgrade}

已在 `v1.6.0` 上的站点升级到 OINK 1.7.0 无需修改模板或样式结构。升级前请核对[升级到 1.7.0](/zh/docs/admin/upgrade/#preparing-1-7)中的 Paper 强调色回退选项、快捷键变更、`rich_copy` 开关，以及开启 `params.map` 或 `params.video_embeds` 时的 CSP 规则。

`v1.7.0` 标签发布后，固定模块版本并验证构建：

```sh
hugo mod get github.com/pgsty/oink@v1.7.0
hugo mod tidy
hugo --environment production --minify --printPathWarnings
```

提交更新后的 `go.mod` 与 `go.sum`，保持构建告警可见，切勿启用 `--panicOnWarning` 或 `HUGO_PANICONWARNING`。
