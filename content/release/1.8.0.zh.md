OINK 1.8.0 将视觉体系扩展为 **六套风格** 与各自独立的深色模式——恢复 Paper 的经典暖纸阅读配色，新增 **GitHub** 与 **News**，将 **Ink** 重构为楷体笔墨的写本风格，将深色 **Terminal** 打磨为克制的荧光屏——同时用一套主题控件栏取代各浏览器不一致的原生音视频条，并统一以原生 Markdown 的 `> [!SOCIAL]` 提示块引用社交帖子。主题使用纯 CSS，可在任意 Hugo edition 上构建（已在 Hugo `0.170+` 上测试），不再声明最低 Hugo 版本，也无需 Sass 编译器，详见[工具链契约](/zh/docs/design/architecture/#hugo-toolchain)。

## 六套视觉风格与独立深色模式 {#presets}

风格菜单现提供 **Paper**、**Slate**、**GitHub**、**Ink**、**News** 与 **Terminal** 六套鲜明的阅读外观，全部编入同一份纯 CSS 样式表，不发起外部字体请求，并配备各自独立的 Giscus 评论区样式表。每套深色模式都沿用浅色模式的字体编排，但拥有独立的夜间配色，而非机械反相。

- **Paper（`preset: paper`，默认）**：回归经典的暖白纸面外观——画布 `#f7f6f3`、墨色 `#21201c`，正文与标题均采用 IBM Plex Sans 配系统黑体，蓝色链接（`#2b5f8c`，深色 `#7db5e6`）重新作为强调色，正文链接恢复半粗体，表格保持外框与原字重，引用左侧恢复细线。所有预设共用的排版提升完整保留：直立 `OINK Kai` 汉字强调、裸 `<kbd>` 键帽、柔和列表符号、表格等宽数字与中日韩标题零字距。
- **Slate（`preset: slate`）**：保持冷灰蓝的技术风格，使用 Inter、Chakra Petch 展示标题、IBM Plex Mono 代码字体与系统黑体。
- **GitHub（`preset: github`，实验）**：忠实还原 GitHub 渲染 README 的浅色（`#ffffff` / `#1f2328`）与深色（`#0d1117` / `#f0f6fc`）样式：GitHub 系统字体与等宽栈、`16 px` / `1.5` 正文、半粗体标题与 `h1`/`h2` 底线及前置链式锚点、灰底代码块（带标题时为文件框）、按内容收缩的全边框斑马纹表格、GFM 提示块配色、`0.25em` 分隔线、侧栏当前行竖条与绿色主按钮。数值源自 `github-markdown-css` `5.9.0` 与 `@primer/primitives` `11.10.0`（MIT），为满足无障碍对比度微调了三处（深色主按钮悬停 `#268838`、浅色选中标签下划线 `#bc4c00`、深色焦点环沿用链接蓝），汉字强调沿用直立 `OINK Kai`。
- **Ink（`preset: ink`，实验）——写本**：重塑为手写宣纸页面，暖色纸面 `#f3ead7` 向窗口边缘渐深至 `#e8dabd`，以墨色 `#241a10` 与朱砂 `#a8321b` 为双墨。西文通篇使用 Palatino（正体标题、斜体分节、正文字重并带一丝洇墨）；汉字在标题与界面用楷体（`OINK Kai` 新增粗楷体声明以命中已安装的粗楷体）、正文用仿宋（`OINK Fangsong`，缺失时回退宋体）。每节以收锋笔触起笔，引用挂在渐淡朱砂笔触上，中文加粗改为朱砂着重号，博客文章与书籍章节首段带朱砂首字下沉，导航当前行带朱砂圆点。**深色 Ink** 为紫青绀纸（`#1b1730` → `#120f22`）上的金银写经：泥银正文 `#e3ddd0` 配泥金标题与强调色 `#dcb766`。
- **News（`preset: news`，实验）——印本**：铅印报栏风格，灰色新闻纸 `#f0eee8` 配油墨黑 `#161616` 与专色蓝 `#1f4f7a`，全站零圆角、零阴影。书版衬线配宋体正文、粗重 Times New Roman 配宋体-简 Black（Windows 为粗黑体）标题、支持 Didot/Bodoni 报头字标；导航、菜单、搜索与列表共用正文衬线，使整页读如同一张印刷版面。页头与页题下设双线，标题下排副题与大写日期线，分节采用粗细双线，引用为上下加线的拉引，表格敞开于两条墨线之间。**深色 News** 取暗房意象：`#0f0f0f` 底色上的银盐文字 `#d8d6d1` 配安全灯橙 `#f2804a` 链接与窗口一角微光。
- **Terminal（`preset: terminal`，实验）**：浅色 Terminal 保持不变；**深色 Terminal** 改写为克制的荧光屏——`#050806` 底色配浅灰绿正文 `#c9d2cc`，荧光绿 `#3dff7a` 专留给微光标题、链接、强调色与导航/搜索当前行光标条，琥珀色 `#e5b45a` 用于标题井号、强调与引用竖线，辅以淡淡扫描线与多色相语法高亮（关键字绿、字符串琥珀、数字青、名称浅灰、注释暗淡）。

`params.ui.theme_color` 仍可在任意预设中覆盖强调色；`bin/check-presets.py` 现同步在渐变画布极值（`--td-preset-canvas-edge`）上校验 WCAG AA 对比度。

## 外观菜单与交互式风格卡片 {#appearance}

- **固定的六套风格网格**：外观菜单与 `T` 快捷键统一按固定顺序排列——上排 **Paper、Slate、GitHub**，下排 **Ink、News、Terminal**。包含 3、5 或 6 套风格时面板展宽至 `24 rem`、按三列与下方三个明暗卡片（浅色、深色、跟随系统）对齐，2 或 4 套时保持两列；在 `320 px` 手机底部抽屉中按钮改为图标在上、名称在下，避免截断。
- **准确反映明暗选择的触发图标**：只要菜单包含明暗选项，顶栏触发按钮就按读者选择显示对应图标——浅色为太阳、深色为月亮、跟随系统为半实心圆——并由首屏内联脚本在绘制前写入 `data-td-color-mode`，杜绝闪烁；仅提供风格切换时显示调色板图标。
- **快捷键提示与分组名统一**：开启键盘导航且设备支持悬停时，两个分组标题显示 **风格（T）** / **Style (T)** 与 **明暗（Y）** / **Color (Y)**（读者关闭单键快捷键时自动隐藏提示）；英文分组标题在 32 份语言包中统一精简为 Color 体系。
- **首页交互式风格卡片**：Landing 页 `capabilities` 组件展板条目现支持 `preset: <名称>`；当该预设位于站点 `preset_menu` 中时，卡片会渲染为可原地切换风格的按钮（`data-td-preset-select` 与 `aria-pressed`），读者可在首页直接点击预览六套风格。

## 音视频统一单进度条控件 {#media}

本地[音频](/zh/docs/components/audio/)与[视频](/zh/docs/components/video/)播放器现共用主题绘制的统一控件栏（`.td-media__controls`），解决 Chromium、Firefox 与 Safari 原生控件样式不一或出现双进度条的问题。

- **三色单轨进度条**：每个播放器只画一条进度滑块，在同一轨道上叠放已播放时间（页面强调色）、已缓冲区间（较深中性色）与未加载部分（浅色中性色），在六套预设及浅色、深色模式下已播放色与两种中性色的对比度均不低于 `3:1`。进度条造型随预设变化：Paper 与 Slate 为圆角药丸，GitHub 为 `8 px` 圆条，Ink 与 News 为利落直角，Terminal 为方块光标配强调色调的缓冲段。
- **完整的播放控制**：包含播放/暂停、已播放时间、单轨进度条、总时长、倍速按钮（在 `1×`、`1.25×`、`1.5×`、`2×`、`0.75×` 间循环），以及悬停或聚焦时展开音量条的静音按钮（触屏粗指针上隐藏，交由设备音量键控制）。视频另提供字幕开关（配置 `track` 时）、让控件栏始终位于画面下方的全屏按钮，以及点击画面切换播放/暂停。
- **键盘、响应式、RTL、打印与无脚本回退**：方向键步进 5 秒，Page 键步进 10%，Home/End 跳至首尾；焦点在控件栏内时全站单键快捷键自动让位。窄栏下进度条自动独占一行，RTL 页面中控件栏保持从左到右排列，强制颜色模式映射为系统色（`Highlight`、`GrayText`、`Canvas`），打印时隐藏控件栏；禁用 JavaScript 时保留浏览器原生播放器控件。

## 原生 `[!SOCIAL]` 帖子引用卡片 {#social}

社交帖子引用采用原生 Markdown 的 `> [!SOCIAL]` 提示块语法：标题行写作者名与行内代码形式的账号，紧随其后的块属性行填写 `avatar`、`date`、`url` 与 `platform`。

````markdown {title="源码"}
> [!SOCIAL] Ron `@RonVonng`
>
> 一套面向工程的 Hugo 文档主题，六套视觉风格，零 Node 工具链。
>
> ![OINK 首页](/images/hero-light.webp)
{avatar="images/ron-vonng.webp" date="2026-11-28" url="https://x.com/RonVonng/status/1871040275575124082" platform="x"}
````

- **纯 Markdown 处处可读**：在 GitHub、编辑器预览或 Obsidian 中，源码本身就是一段清晰的引用块；站点的 Markdown 与 LLMS 输出也会按原样保留提示块和属性行。
- **正文即页面 Markdown**：行内格式、脚注、支持图片缩放的附图、`gallery` 围栏、本地视频与嵌套 `> [!SOCIAL]` 引用帖均可直接在正文中组合。帖子卡片本身不加载脚本，也不向社交平台发起请求。图片缩放、图集和媒体照常加载各自的页面脚本。嵌套卡片使用 `.td-social .td-social` 紧凑样式。
- **中性的平台图标**：`platform` 默认为 `none`（不显示图标与平台名），支持 `x`、`bluesky`、`mastodon`、`threads`、`weibo`、`zhihu`、`telegram`、`linkedin` 与 `none`。完整写法见[帖子指南](/zh/docs/components/social/)。

## 工具链、多语言与细节修复 {#fixes}

- **深色 Paper 外框表格表头**：表头现使用三级底色 `#262420`，与 `#1f1e1a` 的外框清楚区分。
- **移除最低 Hugo 版本限制**：从 `theme.toml` 与 `hugo.yaml` 移除 `min_version` / `module.hugoVersion.min` 声明；主题使用纯 CSS，已在 Hugo `0.170+` 上测试，无需 Sass 编译器或 Extended 版。
- **资产清单与 32 语种同步**：OINK 1.8.0 包含 **29** 个短代码、`main` 样式表共 **123** 层纯 CSS、`VENDOR.json` 收录 **26** 项内置依赖，**32** 份界面语言包各含 **274** 个键（新增 `ui_preset_github`、`ui_preset_news` 与 8 个 `ui_media_*` 播放器标签，并将 `ui_appearance_mode` 更新为简洁的 Color 体系）。
- **消费站工具更新**：`bin/update-consumers.py --check-appearance` 同步校验 Paper 默认与六套风格菜单。

## 升级到 1.8.0 {#upgrade}

升级固定版本前请核对[升级到 1.8.0](/zh/docs/admin/upgrade/#preparing-1-8-0)：

- **六套风格菜单**：如需向读者开放全部六套风格，设置 `params.ui.preset_menu: [paper, slate, github, ink, news, terminal]`。Paper 恢复经典 `#f7f6f3` 暖白与蓝色强调色；偏好衬线出版版面的站点可选用 `preset: news`，使用 `preset: ink` 的站点请审阅新的暖纸笔墨配色与 Palatino/楷体/仿宋排版。
- **社交帖子写法（不兼容变更）**：1.7.0 的 `social` 短代码已移除，仍调用它的页面会构建失败。帖子引用现统一使用 `> [!SOCIAL]`；可运行 `python3 bin/migrations/oink06.py migrate --site <dir> --only social --write` 自动转换（去掉 `--write` 可先干跑预览），再运行 `python3 bin/migrations/oink06.py check --site <dir>` 列出遗留的调用。
- **自定义媒体样式**：若站点 CSS 曾定制 `.td-media__progress`，请移除或改为适配 `.td-media__controls`。

`v1.8.0` 标签发布后，固定模块版本并验证构建：

```sh
hugo mod get github.com/pgsty/oink@v1.8.0
hugo mod tidy
hugo --environment production --minify --printPathWarnings
```

提交更新后的 `go.mod` 与 `go.sum`，保持构建告警可见，切勿启用 `--panicOnWarning` 或 `HUGO_PANICONWARNING`。
